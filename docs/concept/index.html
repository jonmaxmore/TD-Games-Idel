ศึกห้าสำนัก

ส่งศิษย์จากห้าสำนักไปยืนเฝ้าเส้นทาง หยุดพรรคมารจันทร์โลหิต ธาตุทั้งห้าเสริมและข่มกัน ศิษย์สองสำนักรวมกันได้ยุทธ์ผสาน ตอนออฟไลน์ศิษย์ยังบำเพ็ญเพียรสะสมปราณให้ และเล่น co-op กับเพื่อนได้ 2–4 คนบนเว็บ

ฉากจำลองในกรอบจอโทรศัพท์ใช้ความละเอียดจริงของเกม 180×320 px ขยายแบบ pixel-perfect ศิษย์ยิงศัตรูด้วยเอฟเฟกต์ประจำสำนัก ทุกไม่กี่วินาทีจะเกิดยุทธ์ผสาน
