# ศึกห้าสำนัก: Idle Wuxia Tower Defense — Game Design Document

> ชื่อชั่วคราว: **"ศึกห้าสำนัก" (Five Sects Defense)** · เวอร์ชันเอกสาร 0.1 · ต.ค. 2026
> แรงบันดาลใจด้านกลไก: Flash Element TD (2007) — นำมาเฉพาะแนวคิดเกมเพลย์ (ระบบธาตุ, การปลดล็อกป้อมผสม, ดอกเบี้ย) ไม่ใช้โค้ดหรือ asset ใดๆ ของต้นฉบับ

ข้อมูลเกมทั้งหมด (ตัวเลข, ชื่อ, สกิล) อยู่ในไฟล์ JSON ที่โค้ดเกมจะอ่านตรง:
[`data/sects.json`](data/sects.json) · [`data/enemies.json`](data/enemies.json) · [`data/items.json`](data/items.json) · [`data/effects.json`](data/effects.json)

## 1. สรุปหนึ่งย่อหน้า

เกม Tower Defense แนวจอมยุทธภาพ pixel art เล่นบนเว็บและมือถือ (จอแนวตั้ง) ผู้เล่นคือ "ผู้นำพันธมิตรยุทธภพ" ส่ง **ศิษย์ของห้าสำนัก + หนึ่งสำนักสนับสนุน** ไปวางตามจุดป้องกันเพื่อหยุดการบุกของพรรคมารจันทร์โลหิต สำนักแต่ละสำนักผูกกับ **ธาตุทั้งห้า (โลหะ ไม้ น้ำ ไฟ ดิน)** ซึ่งมีวงจร **สร้างเสริม (相生)** และ **ข่มกัน (相克)** เป็นแกนกลยุทธ์ ศิษย์สองสำนักรวมกันได้ **ยุทธ์ผสาน** 10 แบบ และสามสำนักรวมเป็น **ปรมาจารย์** ระหว่างออฟไลน์ ศิษย์ยัง **บำเพ็ญเพียร** สะสมปราณให้ (hybrid idle) และเล่น **co-op 2–4 คน** แบบ real-time ได้

## 2. วิเคราะห์ตลาดและเทรนด์ 2026

| สิ่งที่เห็นในตลาด | ตัวอย่าง | สิ่งที่เรานำมาใช้ |
|---|---|---|
| Idle TD ทำเงินระยะยาว | The Tower (Tech Tree Games) | ชั้น idle/บำเพ็ญ + research tree ถาวร |
| PvP/merge TD ยอดดาวน์โหลดสูง | Rush Royale | ระบบ merge ศิษย์ → ยุทธ์ผสาน |
| Gacha TD รายได้สูงสุด | Arknights, Age of Origins (~$251M ปี 2025) | ตัวละครมีบุคลิก + สกิลต่อเลเวล แต่ **ไม่ทำ gacha หนัก** (ดู §9) |
| Roguelite เข้ามาทุก genre | Rogue Defense, Lone Tower, Sushi Cat | คัมภีร์ยุทธ์ เลือก 1 ใน 3 ทุก 5 waves |
| Minimal อ่านง่าย ได้รีวิวดี | Thronefall, Bad North | UI น้อย silhouette ชัด |
| Cultivation/xianxia idle แรงมากในจีน-SEA | เกม "บำเพ็ญเซียน" idle จำนวนมาก | ขั้นบำเพ็ญ 5 ขั้นเป็น prestige layer — คุ้นเคยกับผู้เล่นไทย/SEA ที่ดูซีรีส์จีน |
| Short-form video เป็นช่องทาง UA หลัก | TikTok/Reels | ทุกยุทธ์ผสานมี "จังหวะว้าว" cut-in หมึกจีน เหมาะตัดคลิป |

**ช่องว่าง:** ยังไม่มี idle TD ที่ (1) ใช้ธีมจอมยุทธจริงจังแบบ pixel art, (2) มีระบบผสมธาตุลึกแบบ Element TD และ (3) เล่น co-op บนเว็บได้ทันทีโดยไม่ต้องติดตั้ง

**บทเรียนจากรีวิวคู่แข่ง:** ช่วงกลางเกมศัตรูกลายเป็น "กระสอบทราย" และความก้าวหน้าตันที่ ~เลเวล 10 → เราแก้ด้วย (ก) ศัตรูธาตุต่างกันทุก wave บังคับให้ปรับทีม ไม่ใช่แค่อัปตัวเลข, (ข) prestige ที่เปิดเร็ว (ชั่วโมงที่ 2–3), (ค) โค้ง HP แบบ `hp*(1+0.18w)*1.06^(w-10)` ที่จูนด้วย sim อัตโนมัติ

## 3. สไตล์ภาพ: Pixel Art จอมยุทธ "HD-2D-lite"

**ทำไม pixel art เหมาะ:**
- ทีมเล็กผลิตได้เร็ว ตัวละคร 24×32 px วาดได้วันละหลายตัว ใช้ AI ช่วยร่าง + คนเก็บงานได้
- ยังเป็นสไตล์ที่ได้รับความนิยมต่อเนื่องในอินดี้ (Celeste, Sea of Stars, Eastward) และเด่นบน store ที่เต็มไปด้วย 3D
- ไฟล์เล็ก โหลดเว็บเร็ว สำคัญกับ web game
- เข้ากับการ "ผสม" แสงสมัยใหม่: sprite คมแบบ pixel + ชั้นแสงเรืองและ particle แบบ HD ทับด้านบน

**กฎภาพ** (ตัวเลขละเอียดใน `effects.json > render`):
- ความละเอียดภายใน 180×320 ขยายแบบ integer, nearest-neighbour
- Tile 16 px · ศิษย์ 24×32 · บอส 64×64 · กระสุน 8×8
- Master palette 48 สี; แต่ละสำนักใช้ได้ 6 เฉด + สีผิว/เส้นขอบร่วม
- เส้นขอบ 1 px สีเข้ม `#1A1423` ทุกตัวละคร → อ่านออกบนพื้นหลังทุกแบบ
- ฉากเป็นภาพวาดจีนสีน้ำหมึกแบบ pixel (ภูเขา หมอก ศาลา) โทนจาง เพื่อให้ตัวละครเด่น
- UI: กรอบม้วนคัมภีร์, ตราประทับสีแดง, ฟอนต์ pixel ไทย+จีน

**สีประจำสำนัก (อ่านได้ทันทีจากระยะไกล):**

| สำนัก | ธาตุ | สี | Silhouette | อาวุธ |
|---|---|---|---|---|
| สำนักกระบี่เมฆา | 金 โลหะ | `#D9E1EA` เงินขาว | สูง ชูกระบี่ | กระบี่ตรง |
| หุบไผ่หยก | 木 ไม้ | `#5BC46A` เขียวหยก | ผอม ถือขลุ่ยขวาง | ขลุ่ย + เข็มพิษ |
| วังธาราเหมันต์ | 水 น้ำ | `#4FB3FF` ฟ้าน้ำแข็ง | ชุดพลิ้ว ยื่นฝ่ามือ | ฝ่ามือ + แพรไหม |
| สำนักหงส์เพลิง | 火 ไฟ | `#FF5A1F` แดงส้ม | ท่ากว้าง กางพัด | พัด |
| วัดวัชระศิลา | 土 ดิน | `#C99A4A` ทองดิน | ไหล่กว้าง พระถือพลอง | ไม้พลอง / กายเหล็ก |
| หอกระจกไท่จี๋ | ☯ หยินหยาง | `#F2F2F2` ขาว-ดำ | นั่งสมาธิ ไท่จี๋ลอย | แส้ปัดฝุ่น + ยันต์ |

สีไม่ใช่ตัวบอกเดียว: ทุกสำนักมี glyph (金木水火土☯) บนกระสุนและไอคอนสถานะ เพื่อผู้เล่นตาบอดสี

## 4. เนื้อเรื่อง

**โลก:** ยุทธภพแห่ง "แผ่นดินห้ายอดเขา" ห้าสำนักใหญ่เคยร่วมกันผนึกจอมมารเสวี่ยเยว่ไว้ใต้ "จันทร์โลหิต" เมื่อร้อยปีก่อน แต่ความบาดหมางทำให้พันธมิตรแตก

**ผู้เล่น:** ศิษย์ไร้สำนักที่ได้รับ "ตราเจ้ายุทธภพ" โดยบังเอิญ ต้องเดินทางไปขอความช่วยเหลือทีละสำนัก — **การปลดล็อกสำนักใหม่คือความก้าวหน้าของเนื้อเรื่อง** (เทียบกับการปลดล็อกธาตุด้วย "ไม้" ทุก 7 waves ในต้นฉบับ)

**โครงเรื่อง 5 บท (แต่ละบท = 1 แผนที่หลัก + ด่านย่อย):**
1. **หมู่บ้านเชิงเขา** — พบสำนักกระบี่เมฆา + วัดวัชระศิลา บอส: ราชาโจรร้อยมือ, ทูตจันทร์โลหิต
2. **หุบไผ่ในหมอก** — หุบไผ่หยก ปมเรื่อง: ศิษย์ทรยศที่ปลอมตัว
3. **วังน้ำแข็งเหนือ** — วังธาราเหมันต์ ต้องพิสูจน์ตัวด้วยด่านที่มีแต่ศัตรูธาตุไฟ
4. **เมืองเพลิงใต้** — สำนักหงส์เพลิง ศึกสองฝ่ายกับพรรคมารกลางเมือง
5. **ยอดเขาจันทร์โลหิต** — หอกระจกไท่จี๋ร่วมทัพ ศึกจอมมารเสวี่ยเยว่ (ดูดธาตุทีละเฟส ต้องใช้ธาตุที่ข่มเท่านั้น)

**การเล่าเรื่อง:** บทสนทนาสั้น 3–5 บรรทัดก่อน/หลังด่าน ภาพ portrait pixel 64×64 ข้ามได้ทุกฉาก — เนื้อเรื่องเป็นเครื่องปรุง ไม่บังคับอ่าน

## 5. Core Gameplay

### 5.1 ด่านแบบ active (3–5 นาที, 20 waves)
- เส้นทางศัตรูตายตัว มีช่องวางศิษย์รอบเส้นทาง (และ "หลังคา" สำหรับศัตรูกระโดด)
- ใช้ **ตำลึงเงิน** จ้างศิษย์ อัปเลเวล 3 ขั้น: ศิษย์ → ศิษย์เอก → ผู้อาวุโส (แต่ละขั้นปลดสกิลใหม่ ดู `sects.json`)
- **ดอกเบี้ย** ทุกจบ wave จากเงินที่เก็บไว้ (มีเพดาน) — เลือกระหว่างใช้ตอนนี้หรือเก็บไว้โต
- ทุก 5 waves เลือก **คัมภีร์ยุทธ์** 1 ใน 3 (roguelite)
- wave 10 และ 20 เป็นบอส
- โหมดเร่ง x2 / x3

### 5.2 ห้าธาตุ: กลยุทธ์หลัก
- **สร้างเสริม (相生):** โลหะ→น้ำ→ไม้→ไฟ→ดิน→โลหะ — ศิษย์ที่วางติดกับศิษย์ธาตุที่ "สร้าง" ตน ได้ +15% ดาเมจ → ผู้เล่นคิดเรื่อง **การจัดวาง**
- **ข่มกัน (相克):** โลหะข่มไม้, ไม้ข่มดิน, ดินข่มน้ำ, น้ำข่มไฟ, ไฟข่มโลหะ — ศัตรูทุกตัวมีธาตุ ตีธาตุที่ข่ม x1.5, ตีธาตุที่ข่มเรา x0.7 → ผู้เล่นคิดเรื่อง **การเลือกทีม** ต่อ wave
- **หอกระจกไท่จี๋** อยู่นอกวง เป็น support (เปิดเผยมือสังหารล่องหน, บัฟความเร็ว, เพิ่มเงิน)

### 5.3 ยุทธ์ผสาน & ปรมาจารย์
- ลากศิษย์ "ผู้อาวุโส" สองสำนักมารวมกัน → **ยุทธ์ผสาน** 10 แบบ (ครบทุกคู่ของห้าธาตุ) เช่น กระบี่เหมันต์ (โลหะ+น้ำ), ฝ่ามือไอระอุ (น้ำ+ไฟ), หมัดภูเขาไฟ (ไฟ+ดิน)
- คู่ "สร้างเสริม" เน้น support/control, คู่ "ข่มกัน" เน้นดาเมจ — ให้เหตุผลในโลกเกมกับตัวเลข
- รวม 3 สำนัก → **ปรมาจารย์** (1 ตัวต่อแผนที่) เช่น เซียนกระบี่ห้ายอดเขา, เจ้าอาวาสกายเหล็ก — สืบทอดแนวคิด "ครบสามธาตุปลด Rocket tower" ของต้นฉบับ

### 5.4 ชั้น Idle: บำเพ็ญเพียร
- **สำนักใหญ่ของผู้เล่น** มีอาคาร 5 หลัง (หอฝึกยุทธ์, หอคัมภีร์, โรงหลอมกระบี่, สวนสมุนไพร, ลานบำเพ็ญ) ผลิต **ปราณ** ตลอดเวลา รวมตอนออฟไลน์ (สูงสุด 12 ชม.)
- **ด่านลาดตระเวน (auto-battle):** ด่านที่ผ่านแล้ว 3 ดาว ตั้งให้ศิษย์เล่นเองแบบ idle ได้ผลตอบแทน 60%
- กลับเข้าเกม → ฉาก "ศิษย์นั่งสมาธิ ลูกปราณไหลเข้าน้ำเต้า" + ตัวนับวิ่ง → ดูโฆษณาเพื่อรับ x2 (สมัครใจ)

### 5.5 Meta progression
- อัปเกรดอาคารด้วยปราณ → บัฟถาวร (ดาเมจ, เงินเริ่มต้น, เพดานดอกเบี้ย)
- **ขั้นบำเพ็ญ 5 ขั้น** (ฝึกปราณ → สร้างฐาน → แก่นทอง → ทารกวิญญาณ → แปลงเทพ) = prestige: รีเซ็ตอาคาร แลก **แต้มบุญ** → ตัวคูณถาวร
- สะสม **ของวิเศษ** (relic) 30 ชิ้น 4 ระดับความหายาก

### 5.6 Co-op หลายผู้เล่น (2–4 คน)
- **โหมดพันธมิตร:** แผนที่เดียวกัน แต่ละคนมีเงินและช่องวางของตัวเองในโซนของตน
- **ยุทธ์ผสานข้ามผู้เล่น:** ศิษย์ของผู้เล่น A รวมกับของผู้เล่น B ได้ → บังคับให้ร่วมมือ คุยกัน
- **ส่งตำลึงให้เพื่อน** ได้ (สูงสุด 30% ต่อ wave)
- เข้าห้องด้วยรหัส 4 ตัวหรือลิงก์แชร์ (เล่นได้ทันทีบนเว็บ — จุดขายสำคัญ)
- v1 ไม่มี PvP เพื่อเลี่ยง pay-to-win; v2 พิจารณา "ส่งศัตรูไปหาฝ่ายตรงข้าม" แบบ Legion TD

## 6. ศัตรู (สรุป — รายละเอียดใน `enemies.json`)

| ประเภท | ตัวอย่าง | วิธีรับมือ |
|---|---|---|
| พื้นฐาน | สมุนพรรคมาร (ดิน) | อะไรก็ได้ ไม้ข่ม |
| เร็ว | โจรวิชาตัวเบา (ไม้) | control น้ำ/ดิน, โลหะข่ม |
| เกราะ | ยักษ์เสื้อเหล็ก (โลหะ) | ไฟข่ม, คมดาบหลอมเหลวเจาะเกราะ |
| กระโดดหลังคา (air) | นักกระโดดหลังคา | ศิษย์ระยะไกล (กระบี่, ขลุ่ย, ฝ่ามือ) — พระพลองตีไม่ถึง |
| แยกร่าง | หุ่นศพ (น้ำ) | AoE ไฟ/ดิน |
| ล่องหน | มือสังหารเงา | ต้องมีหอกระจกไท่จี๋ หรือไม้ตายสิงห์คำราม |
| ฮีล | ภิกษุโลหิต | โฟกัสกระบี่ single target |
| ปรับตัว | ศิษย์ทรยศ | ผสมหลายธาตุ |

บอสทุกตัวมี **กลไกที่บังคับให้เปลี่ยนแผน** ไม่ใช่แค่ HP เยอะ (ปิดสำนัก, ปิดศิษย์, ดูดธาตุ)

## 7. ไอเทม (รายละเอียดใน `items.json`)

| หมวด | คืออะไร | ตัวอย่าง |
|---|---|---|
| **ของวิเศษ** (relic ถาวร) | passive ตลอดเกม 4 ระดับ | ขนหงส์เพลิง (+15% เวลาไหม้), หยกคู่ใจ (ยุทธ์ผสานใช้เลเวลน้อยลง), ตราเจ้ายุทธภพ (ปรมาจารย์ถูกลง 30%) |
| **ไม้ตาย** (ใช้ในด่าน มีคูลดาวน์) | ปุ่มกดของผู้เล่นเอง ให้มีส่วนร่วมแม้ศิษย์ยิงเอง | กระบี่สวรรค์ทลายฟ้า, ธูปหยุดกาล, ฝนตำลึงเงิน, สิงห์คำราม |

## 9. Monetization & Retention

- **ไม่มีโฆษณาบังคับ** มีแต่ rewarded ads (x2 รางวัลออฟไลน์, ฟื้นชีวิต 1 ครั้ง)
- **IAP:** แพ็กเริ่มต้น, หยก, **Season Pass 30 วัน** (ฟรี + พรีเมียม) ที่ให้ชุดคอสเมติกเป็นหลัก
- **ไม่ทำ gacha ตัวละคร:** ทุกสำนักปลดด้วยเนื้อเรื่อง ลดความเสี่ยงกฎหมาย loot box และสร้างความเชื่อใจ (จุดที่ผู้เล่นบ่นเกมคู่แข่งมากที่สุด)
- **Retention:** ภารกิจรายวัน, อีเวนต์รายสัปดาห์ที่เปลี่ยนกฎ (เช่น "สัปดาห์ไฟข่ม"), leaderboard wave สูงสุดในโหมดไม่สิ้นสุด, co-op กับเพื่อน

## 10. Tech Stack & สถาปัตยกรรม

**ตัวเลือก:** Phaser 3 แทน three.js — เกมเป็น pixel art 2D, Phaser มี sprite sheet, tilemap, pixel-perfect scaling, particle และ WebGL post-FX (bloom) ในตัว ขณะที่ three.js ออกแบบมาสำหรับ 3D และต้องเขียนเองมากกว่า

```
td-games-idel/
├─ packages/
│  ├─ sim/        TypeScript ล้วน: กฎเกม, deterministic (fixed tick 20Hz, seeded RNG) — อ่าน docs/data/*.json
│  ├─ client/     Vite + Phaser 3: render, input, UI, เสียง — เรียก sim
│  └─ server/     Cloudflare Worker + Durable Object "Room" (WebSocket)
└─ docs/          GDD + data
```

**Multiplayer แบบ lockstep (ประหยัดเซิร์ฟเวอร์):**
1. ผู้เล่นส่ง "คำสั่ง" (วางศิษย์, อัปเกรด, ผสาน, ใช้ไม้ตาย) ไปที่ Room
2. Room (Durable Object 1 ตัวต่อห้อง) ประทับเลข tick แล้ว broadcast ให้ทุกคน
3. ทุกเครื่องรัน `sim` เดียวกันแบบ deterministic → เห็นผลเหมือนกัน
4. ทุก 5 วิ client ส่ง hash ของ state; ถ้าไม่ตรงให้ resync จาก snapshot

ข้อดี: เซิร์ฟเวอร์แค่รับส่งข้อความ ใช้ CPU น้อยมาก อยู่ใน **Cloudflare free tier** ได้สบาย (Workers + Durable Objects แบบ SQLite มีใน free plan)

**ขั้นตอนการรัน:**
| ขั้น | คำสั่ง | ที่ไหน |
|---|---|---|
| เล่นคนเดียวบนเครื่องนี้ | `npm run dev` (Vite) | `localhost:5173` |
| ทดสอบ multiplayer บนเครื่อง | `npx wrangler dev` (จำลอง Worker + Durable Object) | `localhost:8787` เปิดหลายแท็บ |
| ขึ้นออนไลน์ฟรี | `npx wrangler deploy` (Workers + static assets) | `*.workers.dev` |
| ภายหลัง | D1 (เซฟ/leaderboard), Capacitor (iOS/Android) | — |

**Save:** v1 เซฟใน localStorage + export code; v2 ย้ายขึ้น D1 ผูกบัญชี
