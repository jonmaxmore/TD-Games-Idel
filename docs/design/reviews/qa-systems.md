### P2-1 เวอร์ชันไม่ตรงกับเซิร์ฟเวอร์ แต่ข้อความบอกว่า "ต้องเปิดเซิร์ฟเวอร์ก่อน"
- **ทำซ้ำ:** เปิด `dev:server` ไว้ แล้วให้ client อัปเดต `PROTOCOL_VERSION` (เกิดจริงระหว่างตรวจ: HEAD ขยับจาก v1 เป็น v2 ขณะเซิร์ฟเวอร์เก่ายังรัน) → ศึกกับเพื่อน → สร้างห้อง
- **คาดหวัง:** ข้อความ `ERROR_TH.version` "เกมเวอร์ชันนี้ไม่ตรงกับเซิร์ฟเวอร์ กรุณาโหลดหน้าใหม่"
- **ที่เกิดจริง:** ปุ่มในล็อบบี้ขึ้นว่าออนไลน์ (probe แค่เปิด socket ได้) แต่กดสร้างห้องแล้วขึ้น "เชื่อมต่อเซิร์ฟเวอร์ไม่ได้ · ต้องเปิดเซิร์ฟเวอร์ในเครื่องก่อน (npm run dev:server)" เซิร์ฟเวอร์ส่ง `{"t":"error","code":"version"}` แล้วปิด 1008 (ยืนยันด้วย `wsv.mjs`)
- **ภาพ:** `shots/pvp-create-attempt.png`
- **ต้นเหตุ:** `packages/client/src/net.ts:78` ส่ง error ก่อน welcome ไปที่ `onMsg` ซึ่งยังเป็น no-op แล้ว `onclose` reject แบบไม่มีเหตุผล → `pvp.ts:72` แสดงข้อความ generic

### P2-5 Event listener และ DOM รั่วทุกแมตช์
- **วัด:** เล่นศึกทั่วไป 10 แมตช์ติดกัน (CDP, บังคับ GC ก่อนวัด): JSEventListeners ที่จุดเดียวกันของวงรอบ 84 → 111 → 138 และ Nodes 463 → 670 → 863 (เพิ่มประมาณ 9 listener และ 65 node ต่อแมตช์) heap 3.5 → 5.6 MB ยังไม่หนัก แต่โตแบบเส้นตรง
- **ยืนยัน:** keydown บน window เพิ่ม 1 ต่อหน้าผลศึกหนึ่งครั้ง (3 → 8 หลัง 4 แมตช์) และ `fullscreenchange` บน document เพิ่ม 1 ทุกครั้งที่เปิดหน้าต่างตั้งค่า (`leak.mjs`)
- **ต้นเหตุ:** `main.ts:381` `addEventListener('keydown', skip, { once: true })` ไม่ถูกถอดถ้าไม่มีการกดปุ่ม และ closure จับ DOM ของผลศึกที่ถูกถอดออกไปแล้วไว้ · `lobby.ts:112` `document.addEventListener('fullscreenchange', show)` ไม่มีการถอด
