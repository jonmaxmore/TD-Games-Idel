# ระบบที่เกมระดับ Release ต้องมี

> ส่วนหนึ่งของ [GDD](../GDD.md) · checklist แยกตาม milestone ใน [GDD §11](../GDD.md#11-roadmap-สู่การวางตลาด)

สิ่งที่แยก "เกมขายจริง" ออกจาก "demo" ส่วนใหญ่ไม่ใช่ตัวเกมเพลย์ แต่เป็นระบบรอบๆ ที่ทำให้ผู้เล่นไว้ใจ เล่นต่อเนื่อง และทีมดูแลเกมได้หลังเปิดตัว

## 1. บัญชีและข้อมูลผู้เล่น
- [ ] เข้าเล่นทันทีแบบ guest (ไม่บังคับสมัคร) → ผูก Google / Apple / อีเมลภายหลัง
- [ ] Cloud save อัตโนมัติ + ย้ายเครื่องได้ + กันเซฟชนกันด้วย version
- [ ] ลบบัญชีจากในแอป (Apple บังคับ) และขอดาวน์โหลดข้อมูลตัวเองได้ (PDPA/GDPR)
- [ ] กู้บัญชีผ่านฝ่ายช่วยเหลือ (รหัสผู้เล่น + ประวัติการซื้อ)

## 2. ความยุติธรรมและความปลอดภัย
- [ ] เซิร์ฟเวอร์ยืนยันผลด่านที่ให้รางวัลหายาก, หอคอย, Async Raid ด้วยการรัน sim ซ้ำจาก seed + คำสั่ง
- [ ] Real-time: ตรวจ state hash ของ lockstep, ranked ใช้ sim บน game server เป็นผู้ตัดสิน
- [ ] ตรวจ receipt IAP ที่เซิร์ฟเวอร์ (App Store Server API / Google Play Developer API) และจัดการ refund
- [ ] Rate limit ทุก endpoint, ตรวจความผิดปกติ (ทรัพยากรเพิ่มเร็วเกิน, ชนะผิดปกติ)
- [ ] ระบบรายงานผู้เล่น + บทลงโทษเป็นขั้น (เตือน → ระงับ ranked → แบน)
- [ ] เก็บ secret ทั้งหมดใน secret manager ของผู้ให้บริการ ไม่ใส่ใน client

## 3. โซเชียลและชุมชน
- [ ] เพื่อน (เพิ่มด้วยรหัส / ลิงก์ / ผู้เล่นที่เพิ่งเล่นด้วย)
- [ ] ชุมนุม (guild): สร้าง/เข้าร่วม, ตำแหน่ง, ภารกิจชุมนุม, ศึกสำนัก (S2)
- [ ] แชทชุมนุมและแชทห้อง: กรองคำหยาบไทย/อังกฤษ, รายงาน, บล็อก, ปิดแชทได้; ห้องจับคู่สุ่มใช้อีโมตแทนข้อความอิสระ
- [ ] กล่องจดหมาย (รางวัลชดเชย, ข่าว, ของขวัญอีเวนต์)
- [ ] แชร์รีเพลย์และคลิป 15 วินาที (ช่วยการตลาดผ่าน TikTok/Reels)

## 4. การแข่งขัน
- [ ] MMR แบบ Glicko-2 แยกต่อโหมด, ลีก 7 ขั้น, season ละ 8–10 สัปดาห์ พร้อมรางวัลปลาย season
- [ ] Leaderboard: ทั้งโลก / ประเทศ / เพื่อน / ชุมนุม
- [ ] จับคู่ด้วย "เงายุทธ์" (AI) เมื่อรอนาน **แสดงให้เห็นว่าเป็น AI**
- [ ] โหมดผู้ชม + ห้องส่วนตัวสำหรับจัดทัวร์นาเมนต์ (S1)

## 5. ประสบการณ์ผู้เล่นใหม่ (FTUE)
- [ ] 10 นาทีแรก: เข้าเกมใน < 15 วินาที → เล่นด่านแรกทันที → ได้ยุทธ์ผสานครั้งแรกภายในด่าน 1-4 ("จังหวะว้าว")
- [ ] ปลดระบบทีละขั้น: idle (หลังด่าน 1-3) → คัมภีร์ (1-6) → Async Raid (จบบท 1) → co-op (บท 2)
- [ ] คำแนะนำตามบริบท (เช่น แพ้ 2 ครั้ง → แนะนำธาตุที่ข่ม), ปิดได้
- [ ] วัด funnel ทุกขั้นของ tutorial เพื่อหาจุดที่ผู้เล่นออก

## 6. Live Ops
- [ ] **Remote config:** ปรับตัวเลขสมดุล ราคา อีเวนต์ ได้โดยไม่ต้องอัปเดตแอป (เก็บใน KV, versioned, rollback ได้)
- [ ] ปฏิทินอีเวนต์ + ระบบ banner + ร้านค้าหมุนเวียน
- [ ] A/B test (แบ่งกลุ่มตาม hash ของ player id)
- [ ] ข่าวในเกม / patch notes
- [ ] Push notification ที่ผู้เล่น **เลือกเปิดเอง**: ปราณเต็ม, สำนักโดนบุก, อีเวนต์เริ่ม (ไม่เกิน 1 ครั้ง/วัน)
- [ ] เครื่องมือแอดมิน: ค้นหาผู้เล่น, ส่งของชดเชย, ดูประวัติการซื้อ, แบน

## 7. ข้อมูลและการวัดผล
- [ ] Analytics events: ออกแบบด้วย skill `product-tracking-design-tracking-plan` ที่ติดตั้งไว้
  (เช่น `stage_started`, `stage_completed`, `combo_merged`, `raid_finished`, `iap_purchased`, `ad_rewarded`)
- [ ] Crash/error reporting (Sentry มี MCP เชื่อมไว้แล้ว)
- [ ] Dashboard KPI: retention, conversion, ARPDAU, สมดุลสำนัก (pick-rate / win-rate ต่อสำนัก)
- [ ] Balance sim: รัน `sim` แบบ headless หลายพันรอบใน CI เพื่อตรวจ win-rate ของวีรชนและสำนัก

## 8. คุณภาพและการเข้าถึง
- [ ] ภาษา: ไทย, อังกฤษ (v1.0) · จีนตัวย่อ/ตัวเต็ม, เวียดนาม, อินโดนีเซีย (S1) — ฟอนต์ pixel รองรับทุกภาษา
- [ ] Accessibility: โหมดตาบอดสี (glyph ธาตุ), ลดแสงกะพริบ, ปิดจอสั่น, ขนาดตัวอักษร, เล่นมือเดียวได้
- [ ] Performance: 60fps บนเครื่องระดับกลาง (เช่น Android 4GB RAM ปี 2022), โหมด Low FX, แบตเตอรี่ไม่ร้อน
- [ ] ขนาดดาวน์โหลดเริ่มต้น < 150MB, โหลดเนื้อหาบทถัดไปภายหลังจาก R2
- [ ] เล่นเนื้อเรื่องแบบออฟไลน์ได้ ซิงก์เมื่อออนไลน์
- [ ] เสียง: BGM เครื่องดนตรีจีน (กู่ฉิน, ขลุ่ย, กลอง) ผสมจังหวะสมัยใหม่, SFX ตาม `effects.json`

## 9. ร้านค้าแอปและการตลาด
- [ ] เรตอายุ IARC, privacy policy, privacy label/data safety form
- [ ] ASO: ชื่อ, คำค้น, screenshot 6 ภาพ, วิดีโอ 30 วินาที (ใช้ฉากยุทธ์ผสาน)
- [ ] เว็บเวอร์ชัน: เล่นได้ทันทีบนเว็บ (CDN) + ลง itch.io / CrazyGames / Poki เพื่อทดสอบตลาดก่อน
- [ ] Pre-registration + Discord + TikTok

## 10. โครงสร้างพื้นฐาน

ดูรายละเอียดที่ [architecture.md](architecture.md):
- Node.js 22 services แยกเป็น `api` / `game` / `worker`
- PostgreSQL 16 + Redis 7 + object storage แบบ S3
- Docker Compose สำหรับรันบนเครื่อง และ managed containers ในภูมิภาค Singapore สำหรับ production

- [ ] เลือกผู้ให้บริการโฮสต์และ managed PostgreSQL/Redis ก่อน M1 staging
- [ ] Backup แบบ point-in-time + ทดสอบกู้คืนเดือนละครั้ง
- [ ] Load test ด้วย k6 (game server, matchmaker) ก่อนเปิดตัว

## 11. CI/CD
- [ ] GitHub Actions: lint + typecheck + unit test + determinism test + balance sim → build web → deploy staging อัตโนมัติ
- [ ] Deploy production ด้วยการกดอนุมัติ, rollback ได้
- [ ] Capacitor build สำหรับ iOS/Android, ส่ง TestFlight / Play internal testing
- [ ] Version gate: เซิร์ฟเวอร์บังคับอัปเดตเมื่อ client เก่าเกินไป (เพราะ sim ต้องตรงกันใน PvP)
