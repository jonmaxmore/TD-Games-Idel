**ทำไมยังต้องมี Async PvP ตั้งแต่เปิดตัว:** เกมใหม่มีผู้เล่นออนไลน์พร้อมกันน้อย ถ้าเปิดด้วย real-time ranked จะจับคู่นานหรือต้องใช้ bot เยอะ Async raid ใช้ผังป้องกันที่ผู้เล่นตั้งไว้ จึงมีคู่ต่อสู้เสมอ เซิร์ฟเวอร์ใช้งานน้อย และสร้างวงจร "ป้องกันสำนักตัวเอง ↔ ไปบุกคนอื่น" ที่ทำให้กลับมาเล่นทุกวัน (ส่วนนี้เป็นจุดแข็งที่พิสูจน์แล้วของเกมแนว Clash) พอผู้เล่นมากพอค่อยเปิด real-time ใน Season 1

## 1. เนื้อเรื่อง
ดูรายละเอียดใน [story.md](story.md) — 5 บท × 12 ด่าน รูปแบบด่านสลับกันระหว่าง ตั้งรับ / บุกค่าย / คุ้มกัน / ปิดล้อม / ดวลบอส / ปริศนา

## 2. ตีสำนัก (Async Raid) — v1.0

**ฝั่งป้องกัน**
- ผู้เล่นมี "ลานสำนัก" (แผนที่ป้องกันส่วนตัว) ที่ปลดช่องวางเพิ่มตามขั้นบำเพ็ญ
- จัดผัง: วางศิษย์ ยุทธ์ผสาน กับดัก (หนามไผ่, บ่อน้ำแข็ง) และเลือกเส้นทางศัตรูจาก 2–3 แบบ
- ผังถูกบันทึกเป็น snapshot บนเซิร์ฟเวอร์ ผู้เล่นอื่นมาบุกได้ตอนเจ้าของออฟไลน์

**ฝั่งบุก**
- เลือกคู่ต่อสู้ 1 ใน 3 ที่ MMR ใกล้กัน เห็นผังป้องกันก่อนบุก 30 วินาที
- คุมกองบุกด้วย "กลองศึก" (ทรัพยากรที่เพิ่มขึ้นตามเวลา) ส่งหน่วยฝ่ายบุก ([`enemies.json > attackerUnits`](../data/enemies.json)) และใช้ไม้ตายฝ่ายบุก
- ผล: 0–3 ดาว (ทะลุถึงศาลาหลัก / ทำลาย 50% / ทำลายทั้งหมด) ได้ถ้วยและตำลึง

**รีเพลย์และการแก้แค้น:** ฝ่ายป้องกันดูรีเพลย์ได้ (บันทึกแค่ seed + คำสั่ง จึงขนาดเล็ก) และกด "แก้แค้น" บุกกลับได้ 1 ครั้ง

**ความยุติธรรม:** ตัวเกมฝั่งผู้เล่นส่งแค่คำสั่งกับ tick เซิร์ฟเวอร์รัน sim ซ้ำเพื่อยืนยันผล ถ้าผลไม่ตรงจะไม่นับและติดธงตรวจสอบ ใช้ค่าสถานะ normalized ตาม "ลีก" ของผู้เล่น (ดู §หลักความยุติธรรม)

**ป้องกันการโดนตีซ้ำ:** โดนบุกแล้วได้โล่ 8 ชั่วโมง ทรัพยากรที่เสียได้สูงสุด 20% ของคลังที่ "ปล้นได้" ไม่แตะหยก

## 3. ล่าบอสพันธมิตร (Co-op) — v1.0
- 2–4 คน แผนที่ใหญ่ แบ่งโซน แต่ละคนมีเงินของตัวเอง
- บอสประจำสัปดาห์ (หมุนเวียน 6 ตัว) มี 3 ระดับความยาก
- ยุทธ์ผสานข้ามผู้เล่นได้: ศิษย์ของ A + ศิษย์ของ B
- ส่งตำลึงให้เพื่อนได้สูงสุด 30% ต่อ wave
- เข้าห้องด้วยรหัส 4 ตัว, ลิงก์แชร์ หรือจับคู่สุ่ม
- เทคนิค: lockstep ผ่านห้องแข่งบน game server (ห้องละ 1 ห้อง) ถ้ามีคนหลุดจะกลายเป็น AI แทน และกลับเข้ามาเล่นต่อได้

## 4. หอคอยพันชั้น — Season 1
- ไต่ชั้นไปเรื่อยๆ ทุก 5 ชั้นเลือกคัมภีร์ยุทธ์ ทุก 10 ชั้นเป็นบอส
- seed ของสัปดาห์เหมือนกันทุกคน จึงแข่ง leaderboard ได้อย่างยุติธรรม
- รางวัลตามชั้นสูงสุดที่ไปถึงประจำสัปดาห์

## 5. ศึกชิงยุทธภพ 1v1 (Real-time, สมมาตร) — Season 1
แนวคิดคล้าย Legion TD แต่สั้นกว่าและเหมาะกับมือถือ:
- สนามแนวตั้ง 2 ครึ่ง เลนของเราอยู่ล่าง ของคู่แข่งอยู่บน (เห็นกันตลอด)
- ศัตรู PvE มาเป็น wave พร้อมกันทั้งสองฝั่ง ใครปล่อยหลุดจะเสียชีวิต
- **ส่งทหาร:** ใช้ตำลึงจ้างหน่วยพรรคมารไปเพิ่มใน wave ถัดไปของคู่แข่ง หน่วยที่ส่งไปจะเพิ่ม "รายได้ต่อ wave" ถาวร เกิดการตัดสินใจระหว่างการป้องกันตัวเองกับการกดดันและลงทุน
- 12 waves หรือจนชีวิตหมด ประมาณ 6–8 นาที
- ก่อนเริ่มเลือก deck 5 สำนัก + 2 ไม้ตาย และเห็น deck ของคู่แข่ง (เปิดโอกาสวางแผนสวนทาง)

## 6. บุก–ตั้งรับ 1v1 (Real-time, อสมมาตร) — v1.0 · โหมดเรือธง esports
- **รอบที่ 1:** A ตั้งรับ (วางศิษย์ real-time) ส่วน B บุก (คุมกองบุกด้วยกลองศึก ส่งหน่วยตามจังหวะ ร่ายไม้ตายฝ่ายบุก)
- **รอบที่ 2:** สลับฝ่าย
- ผู้ชนะคือคนที่บุกได้ลึกกว่า (วัดจาก % ความคืบหน้า + เวลา)
- รอบละ 3 นาที จึงเหมาะกับการดูและการสตรีม
- ฝ่ายบุกเห็นเฉพาะศิษย์ในระยะ "สายลับ" ทำให้เกิดการหลอกล่อ (fog of war เบาๆ)

## 7. 2v2 และศึกสำนัก — Season 2
- 2v2: ศึกชิงยุทธภพแบบทีม ยุทธ์ผสานข้ามเพื่อนร่วมทีมได้
- ศึกสำนัก: แผนที่ยุทธภพ 30 ดินแดน ชุมนุมประกาศสงครามกัน ใช้ผล Async Raid ของสมาชิกสะสมแต้มยึดดินแดน รอบละ 1 สัปดาห์ ได้รางวัลตกแต่งชุมนุม

## 8. อีเวนต์จำกัดเวลา
หมุนเวียนทุก 2 สัปดาห์ ตัวอย่างกฎ: "ไฟข่มทุกอย่าง", "ศัตรูเร็ว x2", "ห้ามใช้ยุทธ์ผสาน", "เทศกาลโคมไฟ" (ฉากพิเศษ + ร้านค้าแลกชุด) อีเวนต์ใหญ่ผูกกับเทศกาลจริง เช่น ตรุษจีน สงกรานต์ ไหว้พระจันทร์ ลอยกระทง

## หลักความยุติธรรมใน PvP (สำคัญต่อชื่อเสียงของเกม)
1. **ค่าสถานะ normalized:** ใน ranked ศิษย์ทุกตัวเป็นเลเวลมาตรฐานเดียวกัน ของวิเศษและบัฟจากสำนักใหญ่ถูกปิด ส่วน Async Raid ปรับตาม "ลีก" ให้ทุกคนในลีกเดียวกันมีเพดานเท่ากัน
2. **Deck ไม่ใช่พลัง:** สิ่งที่นำเข้า PvP คือ deck 5 สำนัก + 2 ไม้ตาย ซึ่ง**ปลดได้ทุกตัวด้วยการเล่น**
3. **วีรชน (จาก gacha) เป็น sidegrade:** มีท่าทางต่างแต่ค่าพลังรวมเท่าศิษย์ปกติ (ตรวจด้วย sim อัตโนมัติ: win-rate ต้องห่างตัวปกติไม่เกิน ±2%) และศิษย์ปกติทุกสำนักมีให้ใช้ฟรีเสมอ
4. **ลีกตาม MMR (Glicko-2):** ศิลา → สำริด → เงิน → ทอง → หยก → ยอดฝีมือ → เทพยุทธ์ รีเซ็ตบางส่วนทุก season
5. **ช่วงที่ผู้เล่นน้อย:** จับคู่กับ "เงายุทธ์" (AI ที่เรียนจากผังหรือรีเพลย์ผู้เล่นจริง) **โดยแสดงให้รู้ว่าเป็น AI**

## สถาปัตยกรรมเทคนิคต่อโหมด

| โหมด | รูปแบบเน็ตเวิร์ก | ยืนยันผล |
|---|---|---|
| เนื้อเรื่อง / หอคอย | เล่นออฟไลน์ได้ ซิงก์ผลภายหลัง | เซิร์ฟเวอร์รัน sim ซ้ำจาก seed + คำสั่ง (เฉพาะด่านที่ให้รางวัลหายาก/leaderboard) |
| Async Raid | HTTP: ขอ snapshot → ส่งคำสั่ง | รัน sim ซ้ำทุกครั้ง (คำนวณถูกเพราะ headless) |
| Co-op / PvP real-time | WebSocket lockstep ผ่าน MatchRoom บน game server | client ส่ง state hash ทุก 5 วิ ถ้าเป็น ranked เซิร์ฟเวอร์รัน sim คู่ขนานเป็นผู้ตัดสิน |
| Matchmaking | คิวใน Redis sorted set ตามภูมิภาค + MMR | — |

ข้อกำหนด `sim`: fixed tick 20Hz, ใช้ RNG แบบ seeded, คณิตศาสตร์แบบ fixed-point หรือจำกัด float ให้ deterministic และมี test รัน sim สองครั้งแล้วเทียบ hash ทุกครั้งที่ CI รัน
