# บทเรียนจาก Mobile Legends, League of Legends, RoV, PUBG Mobile

> ส่วนหนึ่งของ [GDD](../GDD.md) · เอกสารนี้ดูว่าเกมแข่งขันระดับใหญ่ทำอะไรได้ดีในระดับ **ระบบ** แล้วเลือกเฉพาะส่วนที่เข้ากับ idle wuxia TD ของเรา ไม่ได้ตั้งใจจะเปลี่ยนเกมเป็น MOBA หรือ battle royale

## สิ่งที่ 4 เกมนี้มีร่วมกัน
1. **เกมฟรีที่ไม่ขายพลัง แต่ขายความสวย:** รายได้หลักมาจากสกิน, battle pass และคอลแลบ ไม่ใช่การซื้อชัยชนะ เกมไหนเคยมีระบบที่ดูเหมือนจ่ายแล้วได้เปรียบ (เช่น ระบบ emblem ช่วงแรกของ Mobile Legends) ผู้เล่นจะบ่นจนต้องแก้
2. **แมตช์สั้นและจบชัด:** Mobile Legends/RoV ราว 10–20 นาที, PUBG Mobile มีโหมดสั้นเสริม เกมมือถือต้องเล่นจบได้ในช่วงพักสั้น
3. **ลำดับขั้น ranked ที่เห็นชัด + season:** ผู้เล่นมีเป้าหมายระยะยาวและเหตุผลให้กลับมาทุก season
4. **โหมดหมุนเวียนชั่วคราว** (Arcade, Brawl, ARAM, โหมดอีเวนต์) ทำให้เกมไม่จืดโดยไม่ต้องสร้างเกมใหม่
5. **ปรับสมดุลเป็นรอบ พร้อม patch notes:** meta เปลี่ยนเรื่อยๆ ผู้เล่นมีเรื่องให้คุย
6. **สังคมคือเหตุผลที่อยู่ต่อ:** เล่นกับเพื่อน, ทีม, ชุมนุม, การแข่งในมหาวิทยาลัยและในชุมชน
7. **รองรับเครื่องสเปกต่ำ:** ฐานผู้เล่นใหญ่ใน SEA มาจากมือถือราคาประหยัด

## รายเกม: บทเรียนที่จะนำมาใช้

### Mobile Legends: Bang Bang (Moonton) — แข็งแรงมากใน SEA
| ระบบ | ทำไมได้ผล | ใช้ในเกมเราอย่างไร |
|---|---|---|
| ฮีโร่ทดลองฟรีหมุนเวียนรายสัปดาห์ | ได้ลองก่อนซื้อ | **วีรชนทดลองฟรีรายสัปดาห์** 2 ตัว ใช้ได้ทุกโหมด ลดแรงกดดันในการสุ่ม |
| Rank ดาว + บัตรป้องกันดาวตก | แพ้แล้วไม่หมดกำลังใจ | ลีกใช้ระบบ "ดาวยุทธ์" + **ยันต์คุ้มดาว** ได้จากภารกิจ (ไม่ขาย) |
| คะแนนความประพฤติ (credit score) | ลดการ AFK/ก่อกวน | **คะแนนคุณธรรม** ต่ำแล้วเข้า ranked ไม่ได้, สูงได้รางวัลเล็ก |
| สกินระดับต่างๆ + คอลแลบ | รายได้หลัก | ชุดศิษย์มี 4 ระดับ ระดับสูงเปลี่ยนเอฟเฟกต์และเสียง (ไม่เปลี่ยนค่าพลัง) |
| ปล่อยฮีโร่ใหม่สม่ำเสมอ | ข่าวใหม่ตลอด | วีรชนใหม่ 1–2 ตัวต่อเดือน |

### RoV / Arena of Valor (Tencent / Garena) — เกมแข่งขันอันดับต้นในไทย
| ระบบ | ทำไมได้ผล | ใช้ในเกมเราอย่างไร |
|---|---|---|
| ลีกอาชีพและลีกมหาวิทยาลัย/นักเรียนในไทย | วัฒนธรรมแข่งขันระดับรากหญ้า | เมื่อถึงขั้นทัวร์ชุมชน ทำ **"ศึกยุทธภพมหาวิทยาลัย"** ใช้ห้องส่วนตัว + โหมดผู้ชม |
| คอลแลบท้องถิ่น (ศิลปิน, แบรนด์, ตัวละครไทย) | ใกล้ชิดผู้เล่นไทย | ชุดคอลแลบไทย เช่น ชุดนักรบสยาม, ชุดเทศกาลสงกรานต์/ลอยกระทง |
| ระบบ Arcana (เสริมพลังนอกแมตช์) | เคยถูกวิจารณ์ว่าได้เปรียบ | **ไม่ทำตาม:** ranked ของเราปิดของวิเศษและบัฟทั้งหมด |
| สตรีมเมอร์/ครีเอเตอร์ไทย | การตลาดที่คนดูเชื่อ | โปรแกรมครีเอเตอร์ + รหัสสนับสนุน แบ่งรายได้ |

### League of Legends (Riot Games) — เกม PC แต่ระบบดูแลชุมชนเป็นต้นแบบ
| ระบบ | ทำไมได้ผล | ใช้ในเกมเราอย่างไร |
|---|---|---|
| **Clash:** ทัวร์นาเมนต์ทีมในเกม สุดสัปดาห์ | ให้คนทั่วไปได้ "แข่งจริง" | **"ประลองสุดสัปดาห์"** ทีม 2 คน (2v2) หรือชุมนุม แบบ bracket จัดอัตโนมัติ เดือนละครั้ง (Season 2) |
| Champion Mastery | ภูมิใจกับตัวที่เล่นบ่อย | **ความชำนาญสำนัก** 7 ขั้น ได้ตราและกรอบโปรไฟล์ (คอสเมติก) |
| Honor (ให้เกียรติเพื่อนร่วมทีม) | ส่งเสริมพฤติกรรมดี | หลังเกม co-op กด "คารวะ" เพื่อนร่วมทีมได้ เพิ่มคะแนนคุณธรรม |
| Patch ทุก ~2 สัปดาห์ + notes ชัดเจน | meta มีชีวิต | รอบปรับสมดุลทุก 2 สัปดาห์ผ่าน remote config + บันทึกการเปลี่ยนแปลงในเกม |
| จักรวาลเรื่องราวนอกเกม (Arcane) | ขยายแฟนนอกกลุ่มเกมเมอร์ | ระยะยาว: แอนิเมชันสั้น pixel/หมึก เรื่องของแต่ละสำนักบน YouTube/TikTok |
| ARAM (โหมดสบายๆ สุ่มตัว) | ผ่อนคลายจาก ranked | **"ยุทธ์สุ่ม"** สุ่ม deck ให้ทั้งสองฝ่าย ไม่มีผลต่อ rank |

### PUBG Mobile (Krafton / Tencent) — ต้นแบบเศรษฐกิจคอสเมติกบนมือถือ
| ระบบ | ทำไมได้ผล | ใช้ในเกมเราอย่างไร |
|---|---|---|
| Royale Pass | ทำให้ battle pass แพร่หลาย ภารกิจรายวันดึงคนกลับมา | ตั๋วยุทธภพผูกกับภารกิจรายวัน/สัปดาห์ที่ **กระจายไปทุกโหมด** ทำให้ผู้เล่นลองโหมดใหม่ |
| ของซ้ำจากการสุ่ม → แปลงเป็นสกุลเงินแลกของ | ลดความรู้สึกเสียของ | มีแล้ว: เศษชุด ([economy.md](economy.md)) |
| หมุนเวียนแผนที่ + โหมดอีเวนต์ | ของใหม่โดยใช้ของเดิม | map pool ของ PvP ([maps.md](maps.md)) + อีเวนต์ทุก 2 สัปดาห์ |
| ทีม 4 คน + เสียงพูด | เล่นกับเพื่อนสนุกกว่า | co-op 2–4 คน ใช้อีโมตและ "สัญญาณด่วน" (ping) แทนแชทเสียง |
| ลานฝึกซ้อม | ฝึกก่อนเข้าจริง | **ลานฝึกยุทธ์**: ทดลองสำนัก/ยุทธ์ผสานกับหุ่นไม้ ดูดาเมจต่อวินาที |
| รองรับเครื่องสเปกต่ำ | ฐานผู้เล่นใหญ่ | โหมด Low FX, เป้าหมาย 60fps บนเครื่องระดับกลาง |

## ข้อเสนอโหมดเพิ่ม: ศึกสามเลน 3v3 (แรงบันดาลใจจาก MOBA)
แนวคิดที่ใกล้ MOBA ที่สุดโดยยังเป็น TD:
- 2 ฝ่าย × 3 คน แผนที่แนวตั้ง 3 เลน ฐานของแต่ละฝ่ายอยู่ปลายแผนที่ (ศาลาหลัก + ป้อมรอง 2 จุดต่อเลน)
- ผู้เล่นแต่ละคนดูแลเลนของตัวเอง: วางศิษย์ป้องกัน และส่งหน่วยฝ่ายบุกไปตามเลน
- ยุทธ์ผสานข้ามเลนกับเพื่อนร่วมทีมได้, "บอสกลางแผนที่" (เหมือนมังกร/ลอร์ด) ใครชนะจะได้บัฟทั้งทีม
- แมตช์ 10–12 นาที ชนะเมื่อทำลายศาลาหลักฝ่ายตรงข้าม
- **ทำไมไม่ใส่ตอนเปิดตัว:** ต้องมีผู้เล่นออนไลน์พร้อมกัน 6 คนต่อแมตช์ และต้องปรับสมดุลยากที่สุด จึงเป็น **ตัวเลือกสำหรับ Season 3** ถ้า ranked 1v1/2v2 มีผู้เล่นมากพอ ควรทดสอบเป็นโหมดอีเวนต์ก่อน

## สิ่งที่ไม่ควรลอก
- **ระบบเสริมพลังนอกแมตช์ที่ใช้ใน ranked** (emblem/arcana ยุคแรก) ทำลายความเชื่อใจ
- **แชทข้อความอิสระกับคนแปลกหน้า** แหล่งความ toxic อันดับหนึ่ง: ใช้อีโมต/สัญญาณด่วนในแมตช์สุ่ม
- **แมตช์ยาว 20+ นาที** ไม่เหมาะกับผู้เล่น idle/casual ของเรา
- **กล่องสุ่มที่ไม่มีการันตี** ใช้ pity + spark เสมอ
- **ทำ esports ก่อนมีชุมชน** (ดู GDD §1.1)
