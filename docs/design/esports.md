# Esports: ปลายทางของเกม

> ส่วนหนึ่งของ [GDD](../GDD.md) · ตัดสินใจแล้ว: **ปลายทางคือ esports เต็มรูปแบบ** โหมดเรือธงคือ **บุก–ตั้งรับ 1v1**
>
> **ลำดับ (ตัดสินใจล่าสุด):** เปิดตัว v1.0 และ Season 1 เป็น **เกม mass-market ก่อน** (PvE + ranked 1v1 สำหรับผู้เล่นทั่วไป) โปรแกรม esports (ทัวร์ทางการ, ลีก, ผู้บรรยาย) **เริ่มเมื่อเกมแมสแล้ว** ตามเกณฑ์ในตารางบันไดด้านล่าง สิ่งที่ทำตั้งแต่แรกคือรากฐานที่ไม่ปิดทาง esports (sim ที่ตัดสินผลได้, รีเพลย์, ranked ยุติธรรม)

## หลักคิด
- **การแข่งขันคือแกนของเกม** ส่วน PvE (เนื้อเรื่อง, idle, co-op) ทำหน้าที่ 3 อย่าง: ดึงผู้เล่นใหม่, สอนระบบห้าธาตุ, และเป็นรายได้หลักช่วงที่ฉากแข่งยังเล็ก
- **ตัวการแข่งขันเป็นการตลาด ไม่ใช่แหล่งกำไร** รายได้มาจากของในเกมที่ผูกกับการแข่ง (ชุดทีม, pass ทัวร์นาเมนต์, ชุดแชมป์) จึงต้องมีฐานผู้เล่นใหญ่ก่อนลงทุนลีกใหญ่
- **ความเสี่ยงอันดับหนึ่งคือผู้เล่นออนไลน์ไม่พอ** ทุกการตัดสินใจช่วงแรกต้องช่วยให้จับคู่ได้เร็ว

## โหมดเรือธง: บุก–ตั้งรับ 1v1
กติกาหลักอยู่ใน [modes.md §6](modes.md) สรุปเพื่อการแข่ง:
- 2 รอบสลับฝ่าย รอบละ 3 นาที ผู้ชนะคือคนที่บุกได้ลึกกว่า (ความคืบหน้า % แล้วตัดสินด้วยเวลา)
- ก่อนแมตช์: เลือก deck 5 สำนัก + 2 ไม้ตาย (ทั้งของฝ่ายบุกและฝ่ายรับ)
- **ทำไมเหมาะเป็น esports:**
  - เห็นชัดว่าใครเหนือกว่า (แถบความคืบหน้า)
  - จังหวะตื่นเต้นมาเป็นระยะ (ยุทธ์ผสาน, ไม้ตาย, ทะลุแนว)
  - สั้นพอให้ถ่ายทอดได้หลายแมตช์ต่อชั่วโมง
  - ใช้แค่ 2 คนจึงจับคู่ง่าย
- **ศึกชิงยุทธภพ 1v1** (โหมดสมมาตร) เป็นโหมด ranked ที่สอง ไม่ใช้ในการแข่งทางการช่วงแรก

## รูปแบบการแข่ง
| ระดับ | รูปแบบ |
|---|---|
| แมตช์ | Best-of-3 (แต่ละเกม = 2 รอบสลับฝ่าย) · รอบชิง Best-of-5 |
| Ban/Pick | แต่ละฝ่าย ban 1 สำนัก แล้วเลือก deck ภายใต้สำนักที่เหลือ · map เลือกจาก pool 3 แผนที่ (ผู้แพ้เกมก่อนเลือกแผนที่) |
| ทีม (แบบ KOF) | ทีม 3 คน แข่ง 1v1 ทีละคู่ ผู้ชนะอยู่ต่อจนแพ้ ห้ามใช้สำนักเดียวกันซ้ำในทีม · ให้ตัวตนแบบ "ทีม" กับสโมสร/มหาวิทยาลัย โดยตัวเกมยังเป็น 1v1 |
| Patch แข่ง | ล็อก patch 2 สัปดาห์ก่อนทัวร์ใหญ่ |

## บันไดสู่ esports เต็มรูปแบบ
| ขั้น | ทำอะไร | เกณฑ์ไปขั้นถัดไป (สมมติฐาน ต้องตั้งตัวเลขจริงหลัง soft launch) |
|---|---|---|
| 0. Soft launch | ranked + ห้องส่วนตัว ในไทย/SEA | เวลาจับคู่ ranked เฉลี่ย < 30 วิ ช่วงเวลาหลัก |
| 1. ทัวร์ชุมชน | สนับสนุนผู้จัด, สตรีมเมอร์, ทัวร์สุดสัปดาห์ในเกม | มีทัวร์ชุมชนต่อเนื่องทุกสัปดาห์, ผู้ชมสตรีมเติบโต |
| 2. ลีกมหาวิทยาลัย | "ศึกยุทธภพมหาวิทยาลัย" แบบทีม KOF | ทีมสมัครมากพอหลายภูมิภาค |
| 3. ทัวร์ทางการภูมิภาค | ถ้วย season ละครั้ง, tournament pass | รายได้จาก pass/ชุดทีม ครอบคลุมเงินรางวัลส่วนใหญ่ |
| 4. ลีกอาชีพ / ชิงแชมป์ SEA | ทีมอาชีพ, ถ่ายทอดสด | ตัดสินใจจากข้อมูลในขั้น 3 |

## ผลต่อการออกแบบส่วนอื่น
- **โหมด:** บุก–ตั้งรับ 1v1 ranked ย้ายมาออก **v1.0** ([modes.md](modes.md))
- **จับคู่:** เว็บ + มือถืออยู่ pool เดียว, เปิดตัวในภูมิภาคเดียว, bot ที่แจ้งว่าเป็น AI ในลีกล่างเท่านั้น
- **สมดุล:** balance sim ใน CI ทุก patch, pick/win-rate ต่อสำนักบน dashboard, ไม่มีสำนักใดชนะเกิน 53% ในลีกสูง
- **เศรษฐกิจ:** ห้ามมีอะไรที่ซื้อแล้วได้เปรียบใน ranked (เดิมก็เป็นกฎอยู่แล้ว) ชุดทีม/ชุดแชมป์เป็นสินค้าใหม่ของ esports
- **ภาพ:** ทุกเอฟเฟกต์ต้องอ่านออกบนจอถ่ายทอด ฝ่ายบุกกับฝ่ายรับใช้กรอบสีต่างกันชัดเจน
