# เส้นทางหน้าจอ (UI Flow): อะไรควรมี อะไรไม่ควรมี

**สถานะ:** เจ้าของตัดสินแล้ว (2026-11-08): ไม่มีพลังงาน (stamina), ศึกฝีมือเปิดหลังจบบทที่ 1, มีหน้าประชันก่อนศึก · ล็อกอินบน PC ยังไม่ตัดสิน (รอ M1)

**ที่มา:** เจ้าของส่งแผนผัง UI flow แบบมาตรฐานอุตสาหกรรมมาให้ใช้เป็นแนวคิด ไม่ใช่ให้ลอกทั้งหมด เอกสารนี้จึงวิเคราะห์ทีละส่วนว่ารับ ปรับ หรือไม่เอา โดยดูจากบริบทของเกมเรา:
- PC เท่านั้น จอ 16:9 ใช้เมาส์และคีย์บอร์ด เล่นบนเบราว์เซอร์ (ADR 0008)
- แมตช์ละ 3 นาที
- ยังไม่มีเซิร์ฟเวอร์จนถึง M1
- PvP จัดอันดับต้องยุติธรรม (`economy.md`)

ป้ายในตาราง:
- **รับ** = ทำตามแนวคิดนั้น
- **ปรับ** = ทำ แต่เปลี่ยนให้เข้ากับเกมเรา
- **เลื่อน** = ทำ แต่ยังไม่ถึงเวลา
- **ไม่เอา** = ไม่ทำ

## 1. หน้าจอที่มีอยู่ตอนนี้
หน้าแรกทำหน้าที่เป็นทั้งหน้าแรกและล็อบบี้ไปพร้อมกัน ตัวเลือกบนหน้านั้นคือ ศึกทั่วไป, ศึกฝีมือ และค่ายฝึก (และกำลังจะมีศึกปราบ)

เส้นทางคือ หน้าแรก → จัดทัพ → ศึก → ผลศึก → (เล่นอีก / จัดทัพ / ค่ายฝึก / หน้าแรก)

**ปัญหา:**
- เมื่อมีโหมดและระบบเพิ่มขึ้น หน้าแรกจะรก
- ยังไม่มี "บ้าน" ที่บอกผู้เล่นว่าควรทำอะไรต่อ
- ผู้เล่นใหม่เห็นทุกระบบตั้งแต่นาทีแรก

## 2. วิเคราะห์ทีละส่วน

### 2.1 ช่วงก่อนเข้าเกม
| แนวคิด | ตัดสิน | เหตุผลสำหรับเกมเรา |
|---|---|---|
| หน้าโลโก้ (Splash) | **ไม่เอา** บนเบราว์เซอร์ · **เลื่อน** ไปตัวเกมบนเดสก์ท็อป | บนเว็บ ทุกวินาทีก่อนเห็นเกมทำให้คนกดปิด ตัวเกมบนเดสก์ท็อปค่อยใส่โลโก้ไม่เกิน 1.5 วินาที และกดข้ามได้ |
| หน้าโหลดและอัปเดต | **ปรับ** | ตอนนี้เกมเล็ก โหลดเกือบทันที ให้มีแถบโหลดจริงเฉพาะเมื่อโหลดภาพนานเกิน 1 วินาที (เมื่อมีภาพ PixelLab ครบ) การตรวจเวอร์ชันมากับเซิร์ฟเวอร์ (M1) หรือตัวเกมบนเดสก์ท็อป ข้อความแนะนำการเล่นใช้ในหน้าประชันก่อนศึกแทน (ข้อ 2.3) |
| ล็อกอิน | **เลื่อน** ไป M1 · **รับ** หลัก "เล่นได้ก่อน ผูกบัญชีทีหลัง" | ยังไม่มีเซิร์ฟเวอร์ ข้อมูลอยู่ในเครื่อง เมื่อถึง M1 ให้เข้าแบบผู้เล่นรับเชิญก่อน แล้วค่อยผูกบัญชีเมื่อจะเล่นจัดอันดับหรือซื้อของ บน PC ใช้ Google, Discord หรือ Steam แทน Apple หรือ Facebook ขอความยินยอมตาม PDPA ตอนผูกบัญชี |
| หน้าแรก "คลิกเพื่อเริ่ม" | **รับ** | มีเหตุผลเฉพาะของเว็บ: เบราว์เซอร์ไม่ยอมเปิดเสียงจนกว่าผู้เล่นจะคลิกครั้งแรก คลิกนี้จึงใช้เปิดเสียงด้วย หน้าแรกเหลือแค่ชื่อเกม ภาพ และ "คลิกเพื่อเริ่ม" ส่วนปุ่มโหมดย้ายไปอยู่ในล็อบบี้ |
| สร้างหรือเลือกตัวละคร | **ไม่เอา** และให้มี **"เลือกสำนักแรก"** แทน | เกมเราไม่มีตัวละครแทนตัวผู้เล่น ครั้งแรกให้เลือกสำนักเริ่มต้น 1 ใน 5 สำนัก ชุดการ์ดตั้งต้นผูกกับเอกสารการได้ตัวละคร (`acquisition.md` กำลังวิจัย) |

### 2.2 ล็อบบี้ (บ้านของผู้เล่น)
| แนวคิด | ตัดสิน | เหตุผลสำหรับเกมเรา |
|---|---|---|
| ล็อบบี้เป็นศูนย์กลาง | **รับ** | ตรงกลางเป็นภาพปราสาทของเรา ซึ่งโตตามเลเวลปราสาท (`progression.json > castleLevel`) ผู้เล่นจะเห็นความก้าวหน้าทุกครั้งที่กลับบ้าน |
| แถบค่าเงินด้านบน | **ปรับ** | แสดงเฉพาะค่าเงินที่มีอยู่จริงตอนนี้ คือ เหรียญ ทองคำ และแต้มไข่ ไม่เกิน 3 ค่าเงิน ยังไม่มีปุ่ม "+ เติมเงิน" เพราะยังไม่มีร้านจริง หยก (`economy.md`) จะขึ้นแถบเมื่อมีร้าน |
| พลังงาน (stamina) | **ไม่เอา** สำหรับ v1 | แมตช์ 3 นาทีบน PC ควรเล่นได้เท่าที่อยากเล่น พลังงานมักผลักให้จ่ายเงินเติม ซึ่งขัดกับหลัก "ไม่ขายการข้ามเวลาที่ให้พลัง" ถ้ากลัวคนฟาร์มรางวัลเกิน ให้ใช้เพดานรางวัลต่อวันแทน |
| ร้านค้า | **เลื่อน** · เมื่อทำให้เป็นหน้าต่างซ้อน มีหลายแท็บในหน้าเดียว | ตอนนี้ไม่มีอะไรขาย ร้านไข่ที่อยู่ในค่ายฝึกย้ายออกมาเป็นหน้าต่างซ้อนของตัวเอง |
| กระเป๋าหรือคลังไอเทม | **ไม่เอา** | เราไม่มีของใช้ทั่วไป อุปกรณ์ผูกกับตัวละครแต่ละตัวและดูได้ในหน้ารายละเอียดการ์ด กระเป๋าเปล่า ๆ เป็นหน้าที่ไม่มีงานให้ทำ ถ้าวันหนึ่งมีวัตถุดิบหลายชนิดค่อยเพิ่ม |
| ภารกิจรายวัน รายสัปดาห์ และหลัก | **เลื่อน** ไปหลังศึกปราบ | เป็นเครื่องดึงคนกลับมาเล่นที่ดี แต่ต้องมีหลายระบบให้ชี้ไปก่อน เมื่อทำต้องมีปุ่ม "ไปทันที" และ "รับทั้งหมด" ตามแนวคิด |
| กิจกรรม ตั๋วยุทธภพ และป๊อปอัป | **เลื่อน** ไปช่วงไลฟ์ (`liveops.md`) | ป๊อปอัปได้ไม่เกิน 1 ครั้งต่อวัน และไม่เด้งตอนเพิ่งแพ้ (`economy.md`: ห้ามเสนอขายตอนผู้เล่นหงุดหงิด) |
| เช็คอินรายวัน | **เลื่อน** | ทำพร้อมภารกิจ |
| โปรไฟล์ | **รับ** แบบเบา | ชื่อ เลเวลปราสาท ป้ายแรงค์ศึกฝีมือ และสถิติแมตช์ ใช้ "พลังทัพ" เมื่อระบบจับคู่กำหนดสูตรแล้ว (`matchmaking.md`) |
| ตั้งค่า | **รับ** | หน้าต่างซ้อน แบ่งเป็นเสียง (มีแล้ว) การแสดงผล (เต็มจอ ลดเอฟเฟกต์) และปุ่มลัด ส่วนบัญชีมาตอน M1 |

### 2.3 ในศึก
| แนวคิด | ตัดสิน | เหตุผลสำหรับเกมเรา |
|---|---|---|
| หน้าโหลดก่อนศึก | **ปรับ** เป็น **หน้าประชัน** 1.5 วินาที | ศึกโหลดเกือบทันที หน้าโหลดจึงไม่จำเป็น แต่หน้าที่บอกว่า "แม่ทัพเราเจอแม่ทัพใคร" มีประโยชน์ทั้งด้านข้อมูลและบรรยากาศ PvP และใส่คำแนะนำสั้น 1 ข้อได้ |
| HUD | **รับ** (มีแล้ว) | ทางเดินเดียวเห็นได้ทั้งเส้นในจอเดียว จึง **ไม่เอา** แผนที่ย่อ |
| เมนูหยุดเกม | **ปรับ** | ศึกปราบและศึกกับ AI กด Esc หยุดได้ ศึกออนไลน์ (M1) หยุดไม่ได้ ยอมแพ้ได้หลัง 60 วินาที |
| หน้าจบเกมพร้อมปุ่มต่อไป | **รับ** และเพิ่มให้ตรงเกมเรา | ชนะในศึกปราบ: ปุ่มหลักเป็น "ด่านต่อไป" · ชนะในศึกทั่วไปหรือศึกฝีมือ: "อีกแมตช์" · แพ้: ปุ่มหลักเป็น "ลองใหม่" พร้อม **คำแนะนำ 1 ข้อจากศึกนั้น** (เช่น "ศัตรูใช้ตัวบินมาก ลองใส่นักธนู") และปุ่มรองไปค่ายฝึก ทุกกรณีมีปุ่ม "ดูภาพย้อนหลัง" เพราะมีระบบบันทึกศึกแล้ว |

### 2.4 หลักการรวม
| หลัก | ตัดสิน | ใช้กับเกมเราอย่างไร |
|---|---|---|
| หน้าต่างซ้อนแทนการเปลี่ยนหน้า | **รับ** | ตั้งค่า โปรไฟล์ ร้านไข่ และรายละเอียดการ์ด เป็นหน้าต่างซ้อนบนล็อบบี้ กด Esc หรือ X เพื่อปิด ส่วนจัดทัพ ค่ายฝึก แผนที่ด่าน และศึก เป็นหน้าเต็มเพราะมีของให้จัดการเยอะ |
| ซ่อนระบบที่ยังไม่ถึงเวลา | **รับ** | ปลดตามความก้าวหน้า ตารางในข้อ 4 (ร่าง รอผลเอกสารการได้ตัวละคร) |
| ปุ่มหลักเด่นที่สุด | **รับ** | หนึ่งหน้ามีปุ่มหลักเดียว ในล็อบบี้คือ **"ศึกปราบ: ด่านถัดไป"** มุมขวาล่าง จนกว่าจะจบบทที่ 1 หลังจากนั้นเปลี่ยนเป็น **"ศึกฝีมือ"** |
| กฎ 3 คลิก | **รับ** | ดูข้อ 3 |

## 3. เส้นทางเป้าหมาย (v1 ก่อนมีเซิร์ฟเวอร์)
```
เปิดเกม ─► หน้าแรก (คลิกเพื่อเริ่ม · เปิดเสียง)
              │ ครั้งแรก                     │ ครั้งต่อไป
              ▼                               ▼
         เลือกสำนักแรก ─► ด่านสอน 1-1 ─►  ล็อบบี้ ◄───────────────────────┐
                                               │                              │
     ┌───────────────┬──────────────┬──────────┼──────────────┬───────────┐   │
     ▼               ▼              ▼          ▼              ▼           ▼   │
  ศึกปราบ        ศึกฝีมือ      ศึกทั่วไป    ค่ายฝึก      ร้านไข่ ▣    ตั้งค่า ▣ / โปรไฟล์ ▣
 (แผนที่ด่าน)   (แรงค์)       (กับ AI)   (เลื่อนขั้น       (▣ = หน้าต่างซ้อน)
     │               │              │      โรงหลอม เมือง)
     ▼               ▼              ▼
  สรุปด่าน ─► จัดทัพ (มือ 7 ใบ, สับมือ) ─► หน้าประชัน 1.5 วิ ─► ศึก ─► ผลศึก ─┘
                                                     (Esc หยุดเกม: PvE/AI เท่านั้น)
```

**นับคลิกจากล็อบบี้**
| ทำอะไร | คลิก |
|---|---|
| ด่านถัดไป | 2 (ปุ่มหลัก → เข้าศึก ที่หน้าจัดทัพ) |
| ศึกฝีมือ | 2 |
| เลื่อนขั้นการ์ด | 3 (ค่ายฝึก → การ์ด → เลื่อนขั้น) |
| เปิดไข่ | 2 |
| ปิดเสียง | 2 |

## 4. ปลดระบบตามความก้าวหน้า
ตัวเลขจริงอยู่ใน `progression.json > unlocks.features` (ถ้าตารางนี้กับ JSON ไม่ตรงกัน ให้ถือ JSON)

| ระบบ | เปิดเมื่อ | เหตุผล |
|---|---|---|
| ศึกปราบ, จัดทัพ | ตั้งแต่ต้น | แกนหลักของเกม |
| ค่ายฝึก: เลื่อนขั้น | ผ่านด่าน 1-2 | ได้แต้มฝึกจากศึกแรก ๆ แล้ว จึงมีอะไรให้กด |
| ศึกทั่วไป (กับ AI) | ผ่านด่าน 1-5 | ฝึกนอกด่าน |
| โรงหลอม | ผ่านด่าน 1-6 | เมื่อเริ่มมีเหรียญพอ |
| เมือง (ปืนใหญ่ กำแพง) | ผ่านด่าน 1-8 | ระบบเสริมช่วงท้ายบท |
| ร้านไข่ | ผ่านด่าน 1-10 (จบบทที่ 1) | เปิดตอนที่มีแต้มให้ใช้ ไม่ใช่เปิดแล้วว่างเปล่า: ชั้นสามัญซื้อได้ทันที (`collection.json > tiers.common.eggShopFromCastleLevel` = 1) ชั้นสูงกว่าเปิดตามเลเวลปราสาท และร้านบอกทางไปค่ายฝึก |
| ศึกฝีมือ | ผ่านด่าน 1-10 (จบบทที่ 1) | รู้กติกาครบก่อนวัดฝีมือ เป็นการคุ้มครองผู้เล่นใหม่ตาม `matchmaking.md` |

ระบบที่ยังไม่เปิดจะซ่อนไว้ ไม่โชว์เป็นปุ่มเทา ยกเว้นถัดไป 1 ระบบ ที่แสดงเป็นปุ่มล็อกพร้อมบอกเงื่อนไข เพื่อให้มีเป้าหมายข้างหน้า

## 5. ลำดับการทำ
1. รอผลงานที่กำลังทำอยู่ (ศึกปราบ ปรับสมดุล และเอกสารวิจัย) แล้ว merge ก่อน เพื่อไม่ให้แก้ไฟล์เดียวกันชนกัน
2. ทำตามลำดับ:
   - หน้าแรกคลิกเพื่อเริ่ม
   - ล็อบบี้พร้อมแถบค่าเงินและปุ่มหลัก
   - หน้าต่างซ้อน: ตั้งค่า โปรไฟล์ ร้านไข่
   - หน้าประชัน
   - ปุ่มต่อไปในหน้าผลศึก พร้อมคำแนะนำเมื่อแพ้
   - Esc หยุดเกม
3. ปลดระบบตามข้อ 4 หลังเจ้าของอนุมัติเอกสารการได้ตัวละคร
4. ภารกิจและเช็คอินรายวัน: หลังศึกปราบบทที่ 1 เล่นได้ครบ
5. ล็อกอินและร้าน: M1

## เจ้าของตัดสินแล้ว (2026-11-08)
1. **ไม่มีพลังงาน (stamina)** ใช้เพดานรางวัลต่อวันแทนถ้าจำเป็น
2. **ศึกฝีมือเปิดหลังจบบทที่ 1**
3. **มีหน้าประชันก่อนศึก**
