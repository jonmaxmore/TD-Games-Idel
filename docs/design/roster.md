## 1. ภาพรวมและจำนวน

ผู้เล่นเลือกสำนักต้นสังกัด สำนักหนึ่งมีศิษย์ 5 บทบาทเหมือนกันทุกสำนัก แต่ทำงานด้วยกลไกของสำนักนั้น ทิศทาง B ทำให้ทุกสำนักมี **สองหน้า**: หน้า **ตั้งรับ** (ผังลานสำนักที่ป้องกันแทนตอนออฟไลน์) และหน้า **บุก** (หน่วยที่ส่งไปตีผังของผู้เล่นอื่นเป็นระลอก + ไม้ตายบุกที่กดตามจังหวะ) ทุกตัวมีบันไดภาพที่เปลี่ยน **ร่าง ท่า เอฟเฟกต์ เสียง และ UI** ทุกขั้น ไม่ใช่แค่ตัวเลข

| หมวด | ต่อสำนัก | 7 สำนัก | หมายเหตุ |
|---|---|---|---|
| ศิษย์ฝั่งรับ (สำนัก × บทบาท) | 5 | 35 | ขั้นในด่าน 3 ขั้น (`sects.json > upgrade`) |
| หน่วยฝั่งบุก | 4 | 28 | ใช้ร่างศิษย์ซ้ำ + ชุดเดิน |
| ไม้ตายบุก (siege) | 1 | 7 | 4 แบบผูกกับ `attackerArts` ที่มีอยู่ |
| ปรมาจารย์ประจำสำนัก (ไม้ตายตั้งรับ 1 ครั้ง/ด่าน) | 1 | 7 | 3 ตัวใช้ของเดิมใน `grandmasters` |

| **รวมร่างผสาน** | | **91** | + ปรมาจารย์ 7 + ไม้ตายบุก 7 |

## 2. ความรู้สึกที่ต้องการ (Player Fantasy)

**ประโยคเดียว:** "ศิษย์ของข้าโตขึ้นต่อหน้าต่อตา ทุกขั้นได้ท่าใหม่ที่เห็นและได้ยิน และผังที่ข้าออกแบบยืนรับศึกแทนข้าตอนหลับ"

| Aesthetic (MDA) | มาจากกลไกไหนในเอกสารนี้ | ความต้องการ SDT |
|---|---|---|
| **Sensation** | บันไดวิวัฒน์ภาพ (§4): ทุกขั้นได้ท่าใหม่ + เอฟเฟกต์ใหม่ + เสียงชั้นใหม่ | Competence (เห็นผลชัดภายใน 0.5 วิ) |
| **Fantasy** | ศิษย์ → ศิษย์เอก → ผู้อาวุโส → ร่างผสาน → ปรมาจารย์ลงสนาม | - |
| **Expression** | กฎสำนักบังคับวิธีจัดผังต่างกัน, ร่างผสาน 10 แบบต่อสำนักให้เลือกทาง | Autonomy |
| **Challenge** | ฝั่งบุกต้องอ่านผังคู่แข่ง: สำนักไหนขาดอะไร (อากาศ, ล่องหน, ฝูง) | Competence |
| **Fellowship** | ศิษย์สหาย/ร่างผสานข้ามสำนัก: ยืมเพื่อนในชุมนุมได้ | Relatedness |
| **Discovery** | ร่างผสาน 91 แบบ ซ่อนชื่อไว้จนสร้างครั้งแรก (achievement "สร้างร่างผสานครบทุกแบบ" ใน progression §4) | - |

**Bartle/Quantic:** Achiever = ดาว/ฝึก/คอลเลกชันร่างผสาน (PvE) · Competitor = ฝั่งบุก–รับแบบ normalized · Explorer = ร่างผสานและคู่ข้ามสำนัก · Socializer = ศิษย์สหายจากชุมนุม

## 3. กติการ่วม

### 3.1 บทบาท 5 แบบ (จาก sect-allegiance §3)

| บทบาท | id | หน้าที่ | ต้นแบบในข้อมูลเดิม |
|---|---|---|---|
| **กระบี่หน้า** | `striker` | ดาเมจเป้าเดี่ยวสูง ล่าตัวหนาและบอส | `sects[cloud_sword]` |
| **ปราณวง** | `burst` | ดาเมจวงกว้าง จัดการฝูง | `sects[crimson_phoenix]` |
| **ตรึง** | `control` | ช้า หยุด สตัน ขวาง | `sects[frost_tide]` |
| **สะสม** | `stacker` | ดาเมจต่อเนื่อง/debuff ซ้อนชั้น | `sects[jade_bamboo]` |
| **ค้ำ** | `support` | เสริมเพื่อน เศรษฐกิจ **เปิดเผยล่องหน** | `sects[taiji_mirror]` |

- id ของศิษย์: `<sectId>_<role>` เช่น `cloud_sword_striker`
- id ของ 5 sect เดิมใน `sects.json` ยังอยู่ แต่ละตัวกลายเป็น "ต้นแบบ" ของบทบาทหนึ่งในสำนักนั้น (ระบุในตารางแต่ละสำนัก)
- **ทุกสำนักต้องมีคำตอบให้ศัตรูล่องหน** (`enemies[assassin]`) โดยไม่ต้องพึ่งไท่จี๋: ศิษย์ค้ำทุกสำนักได้ "เปิดเผย r=2" ที่ขั้น 2
- **ทุกสำนักมีศิษย์ตีอากาศได้อย่างน้อย 3 บทบาท** (`layer: air` ของ `enemies[leaper]`)

### 3.2 คำศัพท์รูปแบบการโจมตี

| คำ | ความหมาย |
|---|---|
| ใกล้ / กลาง / ไกล | ระยะ ≤1.6 / 2.0–2.8 / ≥3.0 ช่อง (ค่าฐานเดิม: โลหะ 2.6, ไม้ 3.0, น้ำ 2.8, ไฟ 2.4, ดิน 2.0 จาก `sects.json > range`) |
| เดี่ยว | โดนเป้าเดียว |
| ทะลุแนว L | ทะลุทุกตัวในเส้นตรงยาว L ช่อง |
| โซ่ N | กระโดดต่อ N เป้า เลือกเป้าถัดไปที่ใกล้สุด |
| กรวย θ r | รูปกรวยมุม θ ยาว r |
| วง r | รอบตัวศิษย์ รัศมี r |
| ระเบิด r | ที่จุดตกของกระสุน รัศมี r |
| สนาม | ช่องพื้นที่มีผลค้าง (ตีเฉพาะพื้นดิน เว้นระบุ) |
| วางบนทาง | ศิษย์วางบนช่องทางเดิน ขวางศัตรู |
| อากาศ: ได้ / ไม่ได้ | ตีศัตรู `layer: air` ได้หรือไม่ |

### 3.3 ความ deterministic (ข้อบังคับของทุกกลไกในเอกสาร)

- เวลาเป็น **tick** (20 Hz): 1 วิ = 20 tick ทุกคูลดาวน์ในเอกสารเขียนเป็นวินาทีพร้อม tick ในวงเล็บเมื่อสำคัญ
- **ไม่มีการสุ่มในกลไกตัวละครเลย** ทุก "โอกาส" เปลี่ยนเป็นตัวนับ เช่น "ทุกการโจมตีครั้งที่ 4" (ตัวนับต่อศิษย์ เริ่ม 0 รีเซ็ตเมื่อขายหรือผสาน) ข้อยกเว้นเดียวที่ยังสุ่มคือ elite affix เดิม (`enemies.json > elites`, seeded RNG)
- เลือกเป้า: ค่าเริ่มต้น "ไกลสุดตามทาง" เสมอกันใช้ entity id ต่ำกว่า · "ใกล้สุด" เสมอกันใช้ id ต่ำกว่า
- ผลที่ลามเมื่อเป้าตาย ประมวลผลตามลำดับ id ใน tick เดียวกัน ลามได้ **ชั้นเดียวต่อเหตุการณ์ตาย** (กันลูปไม่รู้จบ §9)
- ระยะและรัศมีเสนอให้เก็บเป็นจำนวนเต็มหน่วย 1/100 ช่อง (เช่น 2.6 → 260) เปอร์เซ็นต์เป็นจำนวนเต็ม (ให้ systems-designer ยืนยันกับ `packages/sim` ว่าใช้ fixed-point แบบไหน)
- ไม้ตายตอนออฟไลน์ (ผังถูกบุกขณะเจ้าของไม่อยู่) ยิงด้วย **ตัวเลือกเงื่อนไขที่เจ้าของตั้งไว้ล่วงหน้า** 3 แบบ: (ก) เมื่อชาร์จเต็ม (ข) เมื่อศัตรูตัวแรกผ่าน X% ของทาง (ค) เมื่อศัตรูในระยะ ≥ N ตัว ทุกแบบอ่านจาก state ของ sim จึง replay ได้ตรง

### 3.4 ขั้นในด่าน (ทั้ง PvE และ PvP)

ใช้ `sects.json > upgrade` ตามเดิม: ชื่อ `ศิษย์ / ศิษย์เอก / ผู้อาวุโส`, `costMultiplier [1.0, 1.5, 2.25]`, `statMultiplier [1.0, 1.6, 2.5]`
- **ขั้น 1 (T1)** ได้ท่าโจมตีหลัก (ท่าที่ 1)
- **ขั้น 2 (T2)** ได้สกิลใหม่ (ท่าที่ 2) — เป็นการเปลี่ยนวิธีเล่น ไม่ใช่แค่ตัวเลข
- **ขั้น 3 (T3)** ได้สกิลใหม่ (ท่าที่ 3) และปลดสิทธิ์ผสาน
- ขั้นในด่านเหมือนกันทุกคน จึงใช้ใน PvP ได้เต็มที่ (ไม่ขัดหลัก normalized)

### 3.5 ฝั่งบุก (ศึกเงา, บุก–ตั้งรับ 1v1, ด่านบุกค่ายในเนื้อเรื่อง)

- ฝั่งบุกใช้ **กลองศึก** (`enemies.json > attackerUnits._notes`) ส่งหน่วยของสำนักตัวเอง 4 แบบ + ไม้ตายบุก 1 แบบ
- **ต้นทุนหน่วยยึดตามแม่แบบเดิม** ใน `attackerUnits`: ฝูง 1 (`cultist`) · เร็ว 2 (`runner`) · อากาศ 3 (`leaper`) · พิเศษ 4 (`puppet`/`assassin`/`healer`) · หนา 5 (`brute`) · ปรับตัว 6 (`mimic`)
- **ไม่มีสำนักไหนมีครบทุกแม่แบบ** ทุกสำนักขาด 2 จาก 6 แม่แบบ ผู้บุกจึงต้องอ่านผังและเลือกสำนักให้ถูก
- กฎ: ทุกสำนักต้องมี **หน่วยอากาศ หรือ ทางทำลายตัวขวาง** อย่างน้อยหนึ่งอย่าง (กันผังวัชระศิลาขวางทางจนบุกไม่ได้)
- **ขวัญทัพ (ขั้นของฝั่งบุก):** ขึ้นตามเวลาแบบตายตัว หน่วยที่ปล่อย **หลัง** ถึงขั้นจะเกิดเป็นขั้นนั้น
  - ขวัญ 1: tick 0 · ขวัญ 2: tick 1,200 (นาทีที่ 1) · ขวัญ 3: tick 2,400 (นาทีที่ 2) — ผูกกับรอบ 3 นาทีของบุก–ตั้งรับ ([modes §6](modes.md))
  - ทางเลือก: จ่ายกลองศึก X เพื่อขึ้นขวัญเร็ว 1 ครั้งต่อรอบ (ปุ่มปรับ §11)
  - ขวัญ 2 ปลดความสามารถที่สองของหน่วย ขวัญ 3 ปลดความสามารถที่สาม (ตารางแต่ละสำนัก)
- **ไม้ตายบุก:** ผู้บุกกดเอง มีคูลดาวน์ ใช้ได้หลายครั้งต่อรอบ 4 สำนักใช้ id เดิมใน `attackerArts` (`smoke_poison` → ไผ่หยก, `wall_breaker` → วัชระศิลา, `war_drum` → ไม้เท้าหมื่นลี้, `blood_moon` → จันทร์โลหิต) อีก 3 สำนักเสนอใหม่
- หน่วยศัตรูพรรคมารเดิม (`attackerUnits`) **ยังใช้ในด่านบุกค่าย PvE** ส่วน PvP ใช้หน่วยของสำนัก (ข้อตัดสินใจ D1 §12)

### 3.6 ร่างผสาน

**สองแบบ อยู่ร่วมกัน** (ข้อตัดสินใจ D12):

| แบบ | เงื่อนไข | ผล | ภาพ |
|---|---|---|---|
| **ร่างผสานในสำนัก** (sect-allegiance §3) | ศิษย์ T3 สองตัว บทบาทต่างกัน สำนักเดียวกัน วางติดกัน + ค่าผสาน `comboTechniques.mergeFee` (50) | ได้ 1 ตัว คืน 1 ช่องวาง ค่าพลังตาม `_comboRule`: `(dmgA + dmgB) × comboDmgPct(115%)`, คูลดาวน์ = ค่าเฉลี่ย, ระยะ = ยาวกว่า ต้องอยู่ในช่วง merged/separate DPS 1.1–1.3 (B4) | ร่างของบทบาทหลัก (กำหนดตายตัวในตาราง) + อาวุธ/ของประดับของอีกบทบาท + ท่าใหม่ 2 ท่า |
| **ร่างผสานข้ามสำนัก** | ศิษย์สหาย (ช่องเดียวต่อด่าน) T3 + ศิษย์ T3 ของสำนักตน วางติดกัน | ได้ร่างตามคู่ธาตุ/คู่สำนัก (§6) บทบาทของผลลัพธ์ = บทบาทของศิษย์สำนักตน แล้ว "เสียบ" กลไกคู่สำนักเพิ่ม | ร่างศิษย์สำนักตน + สีเน้นของสำนักสหาย 2 เฉด + อาวุธของสหายที่มือรอง |

- ร่างผสานนับเป็นทั้งสองบทบาท (ภารกิจรายวัน "ใช้บทบาท X")
- วีรชนผสานได้เหมือนศิษย์บทบาทเดียวกัน ได้ร่างผสานเดิม + สีผม/ของประดับหัวของวีรชน (เปลี่ยน palette ในเอนจิน ไม่วาดใหม่)
- แยกร่างผสานไม่ได้ ขายได้ราคาครึ่งหนึ่งของทุนรวม (ตามกติกาขายเดิมของ sim)

### 3.7 ปรมาจารย์ประจำสำนัก

แทนระบบปรมาจารย์ 3 สำนักเดิม (sect-allegiance §3): ไม้ตายตั้งรับ **1 ครั้งต่อด่าน/ต่อการถูกบุก 1 ครั้ง** ลงสนามด้วย cut-in หมึก 0.8 วิ (`effects.json > events.grandmaster`) อยู่ 10 วิ (200 tick) แล้วกลับ
- ใช้ร่างเดิม 3 ตัว: `sword_saint` → กระบี่เมฆา, `fire_sage` → หงส์เพลิง, `iron_abbot` → วัชระศิลา · `taiji_master` คงไว้กับสายไท่จี๋
- ใหม่ 4 ตัว: ธาราเหมันต์, หุบไผ่หยก, ไม้เท้าหมื่นลี้, จันทร์โลหิต

### 3.8 ระบบพลังโลก PvE (ไม่ใช้ใน PvP)

ตาม "หลักสองโลก" ใน economy.md พลังฝั่ง PvE อัปได้และขายได้ เอกสารนี้กำหนด **เฉพาะภาพและหลักไมล์** ส่วนต้นทุน/สกุลเงินให้ economy-designer ลง `economy.json` / `progression.json` (D6)

| ระบบ | ใช้กับ | ขั้น | หลักไมล์ที่เปลี่ยนภาพ |
|---|---|---|---|
| **ดาว ★** | วีรชน (จากตัวซ้ำ/เศษวีรชน) | ★1–★5 | ทุกดาว (§4.3) |
| **ขั้นฝึก +N** | ศิษย์พื้นฐานและวีรชน ต่อบทบาท | +0 ถึง +15 | +5, +10, +15 (§4.4) |

- **ใน PvP:** ค่าพลังจากดาวและขั้นฝึกถูกปิดทั้งหมด วีรชนใช้ "ชุดมาตรฐาน PvP" (ไม้ตายและกลไกเด่นระดับฐาน) เพื่อให้เป็น sidegrade ±2% (CLAUDE.md)
- ภาพของดาว/ขั้นฝึกใน PvP: แสดงเฉพาะส่วนที่เป็น **ของตกแต่งล้วน** (ชุด ★3, กรอบการ์ด, ป้ายชื่อ) ส่วนที่อาจดูเหมือนพลัง (ขนาดกระสุน, ออร่า, trail) ล็อกเป็นมาตรฐาน และมีป้าย "ดาวไม่มีผลใน PvP" (D4)

### 5.1 สำนักกระบี่เมฆา 金 (`cloud_sword`, metal)

**ตัวตน:** เซียนกระบี่ผู้แม่นยำ เย็นชา มีวินัย กระบี่บินคือภาพจำ · สี `#D9E1EA` (`palette.metal`) · **ร่างฐาน:** สูงโปร่งที่สุด จีวรขาวเงิน มวยผมสูง ด้ามกระบี่ทอง (character-design) · สไตล์ผัง: ผังแคบ จุดยิงไม่กี่จุดที่ทำดาเมจเป้าเดี่ยวสูง · จุดอ่อนที่ตั้งใจ: ฝูง (`swarm`) และหุ่นศพแตกร่าง

- **สไตล์บุก:** ส่งน้อยแต่แม่น อากาศ + ล่องหน เจาะผังที่ไม่มีศิษย์ค้ำ

### 5.2 หุบไผ่หยก 木 (`jade_bamboo`, wood)

**ตัวตน:** หมอยาและนักพิษผู้เงียบ ลึกลับ พิษ รากไม้ · สี `#5BC46A` (`palette.wood`) · **ร่างฐาน:** ผอม ตัวเอียงเล็กน้อย ผมยาวบังหน้าครึ่งหนึ่ง (character-design) · สไตล์ผัง: วางศิษย์เป็นกลุ่มตรงช่วงที่ศัตรูเดินเป็นแพ ให้พิษลาม · จุดอ่อน: ตัวหนาเกราะสูง, ศัตรูเร็วที่ผ่านก่อนพิษทำงาน

### 5.6 พรรคไม้เท้าหมื่นลี้ (`beggar`, ชื่อชั่วคราว) — เดือนที่ 2

**ตัวตน:** เครือข่ายคนเร่ร่อนทั่วยุทธภพ ไม้เท้า น้ำเต้าเหล้า ฝูงชน ข่าวสาร ขี้เล่นแต่รู้ทุกเรื่อง · ธาตุ: **เป็นกลาง** (ไม่ข่มและไม่ถูกข่ม D2) · สี: ต้องมีกลุ่ม palette ใหม่ 6 เฉด โทนผ้าปะน้ำตาลเหลือง + คราม (D3) · **ร่างฐาน:** ตัวผอมงอเล็กน้อย เสื้อปะ ผ้าโพกหัว ไม้เท้ายาว เท้าเปล่า · สไตล์ผัง: วางมาก ตัวถูก กระจายเต็มทาง · จุดอ่อน: ตัวหนาเกราะสูง (ดาเมจต่อครั้งต่ำ), ไม้ตายแบบวงที่โดนหลายตัวพร้อมกัน
**หมายเหตุชื่อ:** ห้ามใช้ชื่อพรรคหรือวิชาของกระยาจกในนิยายที่มีอยู่ (เช่น ไม้เท้าตีสุนัข) ชื่อในส่วนนี้ตั้งใหม่ทั้งหมด

- **กฎสำนัก (ตั้งรับ):** ศิษย์ราคาถูกลงแต่อ่อนลง วางได้มากกว่า ได้ตำลึงเพิ่มเมื่อสังหาร (`allegiance.upcoming[beggar]`, sect-allegiance §4) เสนอ: ราคา ×0.7 · ดาเมจ ×0.75 · เพดานช่องวาง +2 · +1 ตำลึงต่อการสังหาร (NOT ASSESSED)
- **กฎสำนัก (บุก) "ฝูงชนหมื่นลี้":** หน่วยราคา −1 กลองศึก (ต่ำสุด 1) แต่ HP −20% · ทุกหน่วยที่ 5 ที่ปล่อย มีขอทานเร่ (หน่วยฝูง) เกิดฟรี 1 ตัว
- **สไตล์บุก:** ท่วมจำนวน ใช้ตำแหน่งเกิดหลายจุดตามเวลา

### 5.7 นิกายจันทร์โลหิต (`blood_moon`, ชื่อชั่วคราว) — เดือนที่ 4

**ตัวตน:** ศิษย์ที่แตกออกจากพรรคมาร (เหตุผลในเนื้อเรื่องตาม sect-allegiance §4) เลือด จันทร์แดง สัญญา พลังแลกความเสี่ยง · ธาตุ: **เป็นกลาง** (D2) · สี: ต้องมีกลุ่ม palette ใหม่ แดงสด + ขาวกระดูก + เงินจันทร์ **ห้ามใช้กลุ่ม `palette.enemy`** เพราะผู้เล่นจะสับสนศิษย์กับศัตรู (D3, D15) + เส้นขอบในสีเงินจันทร์และ glyph 月 · **ร่างฐาน:** ผอมสูง ผ้าคลุมหน้าครึ่งเดียว ตราจันทร์เสี้ยวบนหน้าผาก ชายเสื้อขาดเป็นริ้ว · สไตล์ผัง: เสี่ยง เปิดพิธีตอนคับขัน · จุดอ่อน: ถ้าพิธีพลาดจังหวะ เสียชีวิตฟรี, เพดานพลังพื้นฐานต่ำกว่า

- **กฎสำนัก (ตั้งรับ) "พิธีจันทร์โลหิต":** ยอมเสียชีวิตป้อม 1 ดวง → ศิษย์จันทร์โลหิตทั้งหมด +40% rate 10 วิ (200 tick) คูลดาวน์ 45 วิ (900 tick) ใช้ไม่ได้ถ้าเหลือชีวิต 1 ดวง (`allegiance.upcoming[blood_moon]`, sect-allegiance §4) ตอนออฟไลน์ยิงตามเงื่อนไขที่ตั้งไว้ (§3.3)
- **กฎสำนัก (บุก) "บูชายัญ":** แตะหน่วยของตนบนสนามเพื่อสังเวย: หน่วยในรัศมี 1.5 ช่องฟื้น 20% HP และไม่ติดสถานะ 2 วิ (คูลดาวน์ 8 วิ)
- **สไตล์บุก:** ขบวนที่ดูแลตัวเองด้วยการสังเวยและฟื้น

## 7. วีรชน (gacha) 32 คน

### 7.1 กติการ่วม

- วีรชนมี **สำนักและบทบาท** (sect-allegiance §5.2) แทนศิษย์พื้นฐานบทบาทเดียวกันในสำนักตน (บทบาทละ 1 ตัว) หรือใช้เป็น **ศิษย์สหาย** ในสำนักอื่น
- **ฝั่ง PvE:** อัปดาว ★1–★5 และขั้นฝึก +0..+15 ได้ (ขายได้ตามหลักสองโลก)
- **ฝั่ง PvP (รวมศึกเงา):** ค่าพลัง normalized เท่าศิษย์พื้นฐานบทบาทเดียวกัน ใช้ "ชุดมาตรฐาน PvP" = กลไกเด่น + ไม้ตายระดับฐาน (ไม่มีผล ★3/★5) ต้องผ่าน `powerBudgetRule` ใน `heroes.json`: win-rate ห่างศิษย์พื้นฐานไม่เกิน ±2%
- **ไม้ตายวีรชน:** ชาร์จด้วยตัวนับจำนวนการโจมตี (จำนวนเต็ม) เต็มแล้วผู้เล่นกดเอง (ออนไลน์) หรือยิงตามเงื่อนไขที่ตั้งไว้ (ผังออฟไลน์ §3.3) ไม่สุ่ม
- **ดาว (PvE):** ★2 และ ★4 = ค่าพลัง (สูตร §8) · ★3 = อัปกลไกเด่น · ★5 = ไม้ตายตื่นรู้ (ภาพ §4.3)
- **แม่ทัพบุก (เฟส 5):** วีรชนเลือกเป็น "แม่ทัพ" ของการบุกได้ 1 ตัว แทนไม้ตายบุกของสำนักด้วย "ไม้ตายบุก" ของวีรชน ซึ่งแปลงจากไม้ตายตั้งรับตามกฎตายตัว: ไม้ตายดาเมจ → ผนึกศิษย์ในรูปทรงเดียวกัน 3 วิ · ไม้ตายควบคุม → ศิษย์ในรูปทรง −40% rate 4 วิ · ไม้ตายค้ำ → หน่วยของตนในรูปทรงได้ผลกลับด้าน (เช่น +rate → +ความเร็ว) ใช้ร่างวีรชน + ชุดเดิน 18 เฟรม
- id hero_1–24 ใช้ของเดิม ชื่อและ `sidegrade` ยกมาจาก `heroes.json` · hero_25–32 เป็นข้อเสนอใหม่
- ช่องว่างบทบาทของวีรชนในแต่ละสำนักตั้งใจให้ต่างกัน (แต่ละสำนักไม่มีวีรชนอย่างน้อย 1 บทบาท) เพื่อให้ banner แต่ละรอบมีเหตุผลต่างกัน

## 8. สูตร

ทุกค่าที่ไม่ได้อ้าง data = ข้อเสนอ **NOT ASSESSED**

1. **ขั้นในด่าน:** `stat(T) = baseStat × upgrade.statMultiplier[T-1]` → [1.0, 1.6, 2.5] · `cost(T) = baseCost × upgrade.costMultiplier[T-1]` → [1.0, 1.5, 2.25] (`sects.json > upgrade`)
2. **ร่างผสาน:** `dmg = (dmgA + dmgB) × comboDmgPct / 100` (115) · `cooldown = (cdA + cdB) / 2` · `range = max(rangeA, rangeB)` · ข้อบังคับ `1.1 ≤ DPS(merged) / (DPS(A) + DPS(B)) ≤ 1.3` (`comboTechniques._comboRule`)
   - ตัวอย่าง: กระบี่หน้าโลหะ T3 dmg = 22 × 2.5 = 55, ตรึงน้ำ T3 dmg = 17 × 2.5 = 42.5 → กระบี่เหมันต์ dmg = (55 + 42.5) × 1.15 = 112.1 (ก่อนผลกลไก)
3. **กฎกระบี่เมฆา:** `crit = (hitCount mod 4 == 0)` · `dmgCrit = dmg × 2`
4. **กฎหงส์เพลิง (ไฟสะสม):** `burnDps(t) = burnBase × (100 + min(50, 10 × floor(t / 20))) / 100` โดย t = tick ที่ติดไฟต่อเนื่อง (รีเฟรชไม่รีเซ็ต t, ไฟหมดแล้วรีเซ็ต) → สูงสุด ×1.5 ที่ 5 วิ
   - ตัวอย่าง: `burnBase` 6 dps (data lvl1) → วินาทีที่ 0 = 6, วินาทีที่ 3 = 7.8, วินาทีที่ 5+ = 9
5. **กฎธาราเหมันต์:** `dmgVsSlowed = dmg × 115 / 100` · หนาวสะสม: `slowPct = 6 × chill` (chill 0–5) ที่ 5 → แข็ง 30 tick, กัน 60 tick
6. **กฎวัชระศิลา (ขวาง):** ศิษย์บนทางสถานะ `blocking(N, D)` → ถอยหลบ C tick → กลับ `blocking` · ศัตรูที่ถูกขวางหยุดและ "ตี" ศิษย์ (ดาเมจลด D ลงตาม `dmgEnemy / blockDurability` ถ้าระบบต้องการ ข้อเสนอเริ่มต้น: ไม่ลด D เพื่อความง่าย)
7. **กฎไม้เท้าหมื่นลี้:** `cost = round(base × 0.7)` · `dmg = base × 0.75` · `slotCap = mapSlots + 2` · `+1 silver/kill`
8. **กฎจันทร์โลหิต:** `rate × 1.4` นาน 200 tick คูลดาวน์ 900 tick เงื่อนไข `lives > 1`
9. **ขวัญทัพ:** `morale(tick) = 1 + (tick ≥ 1200) + (tick ≥ 2400)`
10. **ดาว (PvE):** ตัวคูณพลัง `[1.00, 1.08, 1.16, 1.24, 1.32]` ตาม ★1–★5 (★3/★5 มีผลกลไกเพิ่ม) → ใน PvP = 1.00 เสมอ
11. **ขั้นฝึก (PvE):** `1 + 0.02 × N`, N = 0..15 → เพดาน 1.30 → ใน PvP = 1.00
12. **งบวีรชน PvP:** `|winRate(hero) − winRate(base same role)| ≤ 0.02` (`heroes.json > powerBudgetRule`)
13. **ตัวคูณธาตุใหม่:** ข่ม ×1.2 / ถูกข่ม ×0.85 (sect-allegiance §5.1 เสนอไว้ ยังไม่ลง data) · สำนักเป็นกลางใช้ ×1.0 ทั้งสองทาง

## 9. กรณีขอบ (Edge Cases)

| กรณี | การจัดการ |
|---|---|
| พิษ/ผง/รอย/เลือดลามเมื่อเป้าตาย แล้วตัวที่รับไปตายใน tick เดียวกัน | ลามชั้นเดียวต่อเหตุการณ์ตาย ตัวที่ตายจากการลามไม่ลามต่อใน tick นั้น ประมวลผลตาม entity id |
| ศิษย์ค้ำหลายตัวให้ออร่าเดียวกัน | ไม่ซ้อน ใช้ค่าสูงสุด (เช่น เปิดเผย, +rate) ออร่าต่างชนิดซ้อนได้ |
| ผสานศิษย์ต่างขั้น | ไม่ได้ ต้อง T3 ทั้งคู่ |
| ศิษย์สหายเป็นสำนักเดียวกับสำนักตน | ไม่ได้ ช่องสหายต้องเป็นสำนักอื่น |
| วีรชนเป็นศิษย์สหาย + ผสานข้ามสำนัก | ได้ ใช้ร่างผสานข้ามสำนักเดิม + palette ของวีรชน (§3.6) |
| ตกดิน (`เงาตกดิน`, `แหหมื่นปม`) ใส่ศัตรูที่ไม่ใช่อากาศ | ไม่มีผล · ใส่หน่วยที่ "ถูกตกดินไม่ได้" (ค้างคาว ขวัญ 3) ไม่มีผล |
| ดันถอย/ย้อน/ดึงกลับเลยจุดเกิด | หยุดที่ช่องแรกของทาง |
| ศัตรูถูกขวางพร้อมถูกดันถอย | ดันถอยชนะ ตัวนั้นหลุดจากการขวาง (นับจำนวนขวางคืน) |
| ประหาร/เปอร์เซ็นต์ HP ใส่บอส | ประหารไม่ใช้กับบอส · %HP ปัจจุบันเพดาน 1% HP สูงสุดต่อครั้ง |
| แข็งติดกันไม่จบ (หลายแหล่ง) | หลังแข็งจบกัน 60 tick ทุกแหล่ง (เหมือนหนาวสะสม) · มึนสะสมกัน 60 tick |
| พิธีจันทร์โลหิตตอนเหลือ 1 ชีวิต | ใช้ไม่ได้ ปุ่มเทา · เงื่อนไขออฟไลน์ข้ามไป |
| พิธีใน async raid (ไม่มี "ชีวิตป้อม" แบบ PvE) | แปลงเป็น "ฝั่งบุกได้ความคืบหน้า +5%" ต่อการใช้ 1 ครั้ง (ข้อเสนอ ให้ systems-designer ยืนยันกับระบบดาว 0–3 ของ modes §2) |
| ไม้เท้าหมื่นลี้ +2 ช่องวางในแผนที่ที่ช่องเต็ม | เพิ่มเฉพาะช่องที่แผนที่กำหนดเป็น "ช่องสำรอง" ถ้าไม่มีให้ +ค่าเทียบเท่า: ราคา −5% เพิ่ม (ปุ่มปรับ) |
| ตำลึงในผังออฟไลน์ (async) | ผังเป็น snapshot ตำลึงไม่มีผลระหว่างถูกบุก กลไกเศรษฐกิจในด่าน (ผงคันหมื่นลี้, เหรียญขอทาน) ไม่ทำงานใน async raid แต่ทำงานใน 1v1 real-time · ข้อนี้ทำให้ไม้เท้าหมื่นลี้อ่อนลงใน async ต้องวัด |
| hero_24 "ศัตรูตัวแรกที่หลุด" ใน async raid | นิยามเป็นหน่วยแรกที่เข้าช่องสุดท้ายของทาง |

| ผังที่ทุกบทบาทเป็นวัชระวางบนทางทั้งหมด (degenerate: ปิดทางถาวร) | C=200 tick บังคับให้มีช่วงเปิด · หน่วยกลิ้งหินและ `wall_breaker` · ตรวจด้วยเกณฑ์ A4 (§13) |
| เศรษฐกิจล้น: ไม้เท้า + เหรียญขอทาน + ผงคัน + กระบี่ในไม้เท้า | ตำลึงจากการสังหารโบนัสรวมเพดาน +3 ต่อการสังหาร |
| ผู้บุกส่งเฉพาะอากาศใส่วัชระศิลา (degenerate) | วัชระมีค้ำ/สะสมตีอากาศได้ + หน้า T3 + ศิษย์สหาย · ตรวจด้วย A4 |
| ผังลอกกันทั้ง ladder | แผนที่ประจำสัปดาห์ + ban สำนักใน season (research §4.2) นอกขอบเขตเอกสารนี้ |
| ภาพ: สองร่างผสานบนกระดานที่หน้าคล้ายกัน | ทุกร่างผสานต้องผ่านการทดสอบ silhouette ดำ (art-bible §6) และมีอักษรพู่กันชื่อท่าบนไอคอน |

## 13. เกณฑ์ยอมรับ (Acceptance Criteria)

**ฟังก์ชัน (sim/bot):**
- A1 ทุกกลไกในเอกสารนิยามได้ด้วย tick จำนวนเต็มและตัวนับ ไม่มี `Math.random` ผ่าน double-run hash test
- A2 กฎใหม่ทุกข้อมี golden ใน `packages/sim/scripts/golden.ts` ผ่าน `npm run sim:golden` และ `npm run sim:parity`
- A3 เกณฑ์ S1–S3 ของ sect-allegiance §7 ผ่านสำหรับทุกสำนักที่ออก (S1 bot ชนะ 1-12 ≥3/4 seed, S2 ห่างกัน ±3%, S3 บทบาทเดียวชนะ ≤1/4 seed)
- A4 **ฝั่งบุก–รับ:** สำหรับทุกคู่สำนัก (15 คู่ที่ 5 สำนัก, 28 คู่ที่ 7 สำนัก) ไม่มีผังรับที่ชนะทุกแผนบุกของ bot และไม่มีแผนบุกที่ชนะทุกผังของ bot (research §5 ข้อ 2)
- A5 วีรชนทุกตัว `|ΔwinRate| ≤ 0.02` ด้วยชุดมาตรฐาน PvP (`heroes.json > powerBudgetRule`)
- A6 ร่างผสานทุกตัวอยู่ในช่วง DPS 1.1–1.3 (`_comboRule`)
- A7 ลีกสูง: ไม่มีสำนักชนะเกิน 53% (esports.md) วัดหลังเปิดจริง
- A8 ทุกสำนักมีศิษย์ตีอากาศ ≥3 บทบาท (นับ T3) และเปิดเผยล่องหนได้ ≤T2 (ตาราง §5.8)

**ภาพและความรู้สึก (playtest):**
- V1 checklist ต่อตัว: ทุกขั้นเปลี่ยน ≥4 จาก 5 ช่อง (ร่าง/ท่า/VFX/เสียง/UI) และทุกขั้นในด่านได้ท่าใหม่ ≥1 ท่า
- V2 ผู้ทดสอบ ≥80% บอกขั้น (T1/T2/T3) ของศิษย์บนกระดานที่ขนาดจริงได้ถูกภายใน 2 วินาที
- V3 ผู้ทดสอบ ≥90% แยกศิษย์จันทร์โลหิตกับศัตรูพรรคมารได้
- V4 ทุกร่างผสานผ่าน silhouette ดำ (art-bible §6) และผู้ทดสอบจำชื่อร่างผสานที่ตัวเองสร้างได้ ≥1 ชื่อหลังเล่น 1 ชั่วโมง
- V5 คำถามหลังเล่น: "อัปขั้นแล้วรู้สึกว่าได้ของใหม่ไหม" ≥70% ตอบใช่ (ตอบโจทย์เจ้าของเกมโดยตรง)
- V6 60fps บนมือถือระดับกลางเมื่อมีร่าง T3 + ร่างผสาน 4 ตัวบนจอ (particle ≤1,500 ตาม `render.maxParticles`)

### 14.2 วิธีลดต้นทุน (ใช้ทุกเฟส)

1. **ร่างฐานเดียวต่อสำนัก** (sect-allegiance §6): rig Blender 1 ตัวต่อสำนัก 5 บทบาทต่างกันที่อาวุธ ท่ายืน หมวก ([tools/blender.md](../tools/blender.md), `npm run art:build`) → sheet "เต็ม" จริงน่าจะใช้แรงราว 0.6 ของการวาดใหม่ (ประมาณการ ต้องวัดจากงานชุดแรก)
2. **ขั้น = overlay + เอนจิน:** ไม่วาดตัวใหม่ ออร่า bloom tint trail ทำในเอนจิน (HD-2D-lite)
3. **หน่วยบุกใช้ร่างศิษย์ซ้ำ** + ชุดเดิน + overlay ฝั่งบุก ค้างคาวเป็นตัวเดียวที่เป็น prop ใหม่
4. **ร่างผสาน = ร่างบทบาทหลัก + overlay อาวุธบทบาทรอง + 14 เฟรม** ไม่วาดตัวใหม่
5. **ผสานข้ามสำนักใช้ palette swap ในเอนจิน** สำหรับสีเน้นของสหาย (ต้องอนุมัติข้อยกเว้น palette ใน art-bible)
6. **ขั้นฝึก +5/+15 เป็นเอนจินล้วน** วาดเฉพาะอาวุธ +10
7. **ภาพการ์ดศิษย์เริ่มจากครึ่งตัว** เต็มตัวเฉพาะปรมาจารย์และวีรชน (sect-allegiance §6)
8. **ร่างผสานใช้ sprite ขยายบนการ์ดไปก่อน** ภาพวาดครึ่งตัวมาเฟส 5
