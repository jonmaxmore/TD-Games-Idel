# เนื้อเรื่องและประเภทด่าน

> ส่วนหนึ่งของ [GDD](../GDD.md) · ด่านทั้ง 60 ด่านอยู่ใน [`data/stages.json`](../data/stages.json)

## ประเภทด่าน

| ประเภท | ไอคอน | ผู้เล่นทำอะไร | ทำไมต้องมี |
|---|---|---|---|
| **ตั้งรับ** | 🛡 | TD คลาสสิก วางศิษย์ป้องกันเส้นทาง | แกนหลักของเกม |
| **บุกค่าย** (reverse TD) | ⚔ | นำขบวนศิษย์ 3–5 คนเดินตามเส้นทางที่ **เลือกได้** ฝ่าป้อมพรรคมาร กดใช้สกิลศิษย์เอง เก็บยาฟื้นพลังระหว่างทาง | ให้ผู้เล่นได้ "เป็นฝ่ายบุก" และฝึกมุมมองที่ใช้ในโหมดตีสำนักกับ PvP บุก–ตั้งรับ |
| **คุ้มกัน** | 🛒 | พาเกวียนยา/ผู้อาวุโสไปถึงปลายทาง วางศิษย์ตามจุดที่เกวียนผ่าน | ผสมการเคลื่อนที่กับการตั้งรับ |
| **ปิดล้อม** | 🏯 | ตั้งรับ 2–3 เลนพร้อมกัน เงินร่วมกัน | ทดสอบการจัดสรรทรัพยากร |
| **ดวลบอส** | 👹 | ศิษย์ 3 คนในสนามเล็ก รับมือกลไกบอสเป็นเฟส | ฉากเด่นของแต่ละบท |
| **ปริศนา** | 🧩 | ศิษย์ที่กำหนดให้และเงินคงที่ หาวิธีชนะ | สอนห้าธาตุแบบลึก เหมาะผู้เล่นสายคิด |
| **ด่านลับ** | ✦ | ปลดด้วยดาว ได้ของวิเศษหายาก | รางวัลสำหรับคนที่เก็บครบ |

**ระบบดาว:** ทุกด่านมี 3 ดาว ดาวแรกได้จากการผ่าน อีก 2 ดาวเป็นเงื่อนไขเฉพาะด่าน เช่น "ชีวิตไม่ลด", "ใช้ไม่เกิน 4 สำนัก", "ผ่านใน 4 นาที"
**ระดับยอดฝีมือ:** ปลดหลังจบบท ศัตรูแข็งขึ้นและมีกลไกเพิ่ม ให้หยกเป็นรางวัล
**ด่านลาดตระเวน:** ด่านที่ได้ 3 ดาวตั้งให้เล่นเองแบบ idle ได้ (ดู GDD §5.4)

## ตัวละครหลัก

| ตัวละคร | บทบาท | สำนัก |
|---|---|---|
| **อาหลิน (ผู้เล่น)** | ศิษย์กำพร้าไร้สำนักที่ได้ "ตราเจ้ายุทธภพ" มาโดยบังเอิญ | ไม่มี → ผู้นำพันธมิตร |
| **ผู้เฒ่าเมฆขาว** | อาจารย์ใหญ่สำนักกระบี่เมฆา ผู้รู้ความลับของตรา | กระบี่เมฆา |
| **หลวงจีนเหล็ก** | ภิกษุอารมณ์ร้อน ใจดี เป็นเพื่อนคู่หูช่วงแรก | วัชระศิลา |
| **ชิงอี** | หมอพิษสาวแห่งหุบไผ่ ไม่ไว้ใจใคร | หุบไผ่หยก |
| **นางพญาเหมันต์** | ผู้ปกครองวังน้ำแข็ง เย็นชา แต่รักษาคำสัญญา | ธาราเหมันต์ |
| **เยี่ยนหง** | ทายาทสำนักหงส์เพลิง ใจร้อน ชอบประลอง | หงส์เพลิง |
| **นักพรตกระจก** | ผู้เฝ้าหอไท่จี๋ พูดเป็นปริศนา | กระจกไท่จี๋ |
| **ซูเฟิง** | ศิษย์พี่ของอาหลิน ภายหลังเผยว่าเป็นไส้ศึกของพรรคมาร (จุดหักมุมบท 2) | กระบี่เมฆา → พรรคมาร |
| **จอมมารเสวี่ยเยว่** | ผู้นำพรรคจันทร์โลหิต ต้องการดูดพลังห้าธาตุ | พรรคมาร |

## โครงเรื่อง 5 บท

แต่ละบทมี 12 ด่าน รูปแบบสลับกันโดยตั้งใจ: ไม่มีประเภทเดียวกันติดกันเกิน 2 ด่าน และทุกบทมีด่านบุกอย่างน้อย 3 ด่าน

### บทที่ 1 — หมู่บ้านเชิงเขา (สอนระบบ)
**ปลด:** สำนักกระบี่เมฆา (ด่าน 1), วัดวัชระศิลา (ด่าน 4)
**เรื่อง:** โจรของราชาโจรร้อยมือปล้นหมู่บ้าน อาหลินช่วยไว้ได้และได้ตราเจ้ายุทธภพจากนักเดินทางที่กำลังจะตาย ผู้เฒ่าเมฆขาวบอกว่าพรรคมารกำลังกลับมา อาหลินต้องรวมห้าสำนักอีกครั้ง
**จบบท:** ดวลทูตจันทร์โลหิต ทูตทิ้งท้ายว่า "ในสำนักของเจ้าก็มีคนของเรา"

| ด่าน | ประเภท | สาระ |
|---|---|---|
| 1-1 | ตั้งรับ | Tutorial วางศิษย์กระบี่ |
| 1-2 | ตั้งรับ | Tutorial อัปเลเวล + ดอกเบี้ย |
| 1-3 | บุกค่าย | Tutorial ขบวนบุก ตีค่ายโจรเล็ก |
| 1-4 | ตั้งรับ | ปลดวัดวัชระศิลา, สอนระฆังทองขวางทาง |
| 1-5 | คุ้มกัน | พาเกวียนชาวบ้านหนี |
| 1-6 | ตั้งรับ | ศัตรูบินครั้งแรก (นักกระโดดหลังคา) |
| 1-7 | ปริศนา | มีแค่ 2 สำนัก สอนธาตุข่ม |

### บทที่ 2 — หุบไผ่ในหมอก
**ปลด:** หุบไผ่หยก
**เรื่อง:** ชิงอีไม่ยอมเข้าร่วมเพราะเคยถูกกระบี่เมฆาหักหลัง ระหว่างที่อาหลินพิสูจน์ตัวเอง ศิษย์พี่ซูเฟิงขโมยคัมภีร์ของหุบไผ่ **หักมุม:** ซูเฟิงคือไส้ศึก
**ด่านเด่น:** บุกค่ายในหมอก (มองเห็นแค่ระยะใกล้), ดวลบอสกับซูเฟิง (ใช้ท่ากระบี่แบบเดียวกับผู้เล่น)

### บทที่ 3 — วังน้ำแข็งเหนือ
**ปลด:** วังธาราเหมันต์
**เรื่อง:** นางพญาเหมันต์ให้พิสูจน์ด้วยการทดสอบสามด่าน (ด่านปริศนาเยอะในบทนี้) ระหว่างนั้นพรรคมารล้อมวัง
**ด่านเด่น:** ปิดล้อม 3 เลนบนสะพานน้ำแข็ง, คุ้มกันนางพญาที่บาดเจ็บ

### บทที่ 4 — เมืองเพลิงใต้
**ปลด:** สำนักหงส์เพลิง
**เรื่อง:** เมืองท่าถูกพรรคมารยึด เยี่ยนหงจะบุกเดี่ยว อาหลินต้องวางแผนตีเมืองคืน (บทที่มีด่านบุกมากที่สุด 5 ด่าน)
**ด่านเด่น:** บุกค่ายแบบเลือกเส้นทาง 3 สาย (หลังคา / คลอง / ตลาด) เส้นทางที่เลือกเปลี่ยนด่านถัดไป

### บทที่ 5 — ยอดเขาจันทร์โลหิต
**ปลด:** หอกระจกไท่จี๋
**เรื่อง:** ห้าสำนักรวมกันครบ บุกยอดเขา ซูเฟิงกลับใจในวินาทีสุดท้าย ศึกจอมมารเสวี่ยเยว่ 3 เฟส (ดูดธาตุทีละเฟส ต้องใช้ธาตุที่ข่ม)
**ตอนจบ:** ผนึกสำเร็จแต่ตราเจ้ายุทธภพแตก ชิ้นส่วนกระจายไปยังดินแดนตะวันตก เป็นปมให้ **Season 1: ดินแดนทะเลทรายตะวันตก** (บทที่ 6–7 + สำนักใหม่)

## การเล่าเรื่องในเกม
- ฉากสนทนาสั้นก่อนและหลังด่าน ไม่เกิน 5 บรรทัด ภาพ portrait pixel 64×64 ข้ามได้เสมอ
- cut-in ภาพหมึกตอนเปิดบทและตอนบอสปรากฏ
- "บันทึกยุทธภพ" (codex) เก็บประวัติสำนัก ตัวละคร และศัตรูที่เจอ ให้ผู้เล่นที่ชอบอ่าน
- เนื้อหา season ใหม่เพิ่มบทใหม่ 2 บทต่อ season (24 ด่าน) + 1 สำนักหรือวีรชนใหม่
