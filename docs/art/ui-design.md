# UI Design: กรอบม้วนคัมภีร์และตราประทับ

> **UI Design Document.** UI kit, icons, fonts, portraits and the in-game HUD for the v1 portrait screen (360×640 internal). Spec and delivery: [art-bible](art-bible.md). Batch 5.

## ภาษาภาพของ UI
- **กรอบม้วนคัมภีร์:** แผงทุกแผงเป็นกระดาษม้วน (หัว-ท้ายม้วนไม้) สีกระดาษเก่า + ขอบหมึก
  - ทำเป็น 9-slice ยืดได้ มุม 8×8
- **ตราประทับแดง `#D2412F`:**
  - ปุ่มหลัก (เริ่มบุก, ยืนยัน)
  - ปุ่มไม้ตาย
  - สถานะสำคัญ เช่น "ชนะ" หรือ ดาว
- **หมึกจีน:** แบนเนอร์ชื่อบอส/ยุทธ์ผสานใช้รอยพู่กันหมึกดำพาดจอ
- **ทอง `#E3B04B`:** ตำลึงเงิน ดาว ตัวเลขคริ ของรางวัล
- ใช้สีจาก `shared` + `env` เป็นหลัก UI ห้ามใช้สีประจำสำนักเป็นพื้นหลังใหญ่ (สงวนไว้บอกสำนัก)

## ฟอนต์
- **ไทย:** ฟอนต์ pixel ไทยที่มีสระบน-ล่างครบ สูงตัวอักษร 12px บนจอ 360×640 อ่านบนมือถือได้
  - ต้องมีใบอนุญาตใช้ในเกมเชิงพาณิชย์ (เช่น OFL)
- **จีน:** ใช้เฉพาะอักษรประจำ (金木水火土☯ และชื่อท่า) วาดเป็นภาพ ไม่ต้องมีฟอนต์จีนทั้งชุด
- **ตัวเลข:** ฟอนต์ pixel 5×7 สีทอง สำหรับดาเมจและตำลึง
- ทีมพัฒนาเลือกฟอนต์ไทย ศิลปินออกแบบแค่ตัวเลขและอักษรจีนที่เป็นภาพ

## HUD ในด่าน (360×640)

```
┌──────────────── 360 ────────────────┐
│ ตำลึง 120 │ ชีวิต 20 │ x1 │ wave 1/6 │  แถบบน 32px
├──────────────────────────────────────┤
│                                      │
│      กระดาน 11×18 ช่อง × 32px         │  352×576 (ขอบซ้ายขวา 4px)
│   ประตูเกิด → ทางเดิน → ประตูสำนัก    │  ประตูทั้งสองอยู่ในกระดาน
│                                      │
├──────────────────────────────────────┤
│ [เริ่มบุก]  [劍][香][銀][吼]  fps     │  แถบล่าง 32px
└──────────────────────────────────────┘
```
- แผงวาง/อัปเกรด/ขายศิษย์:
  - เปิดเป็นม้วนคัมภีร์ลอยเหนือแถบล่าง
  - **ห้ามบังช่องที่ผู้เล่นกำลังเลือก** ถ้าช่องอยู่ครึ่งล่างของกระดาน ให้เปิดแผงที่ครึ่งบน
- ปุ่มต้องกดได้ด้วยนิ้ว: พื้นที่กดอย่างน้อย 44×44 พิกเซลจริงบนจอ (ประมาณ 22×22 ในหน่วยเกมเมื่อขยาย 2 เท่า)
- ข้อความทั้งหมดผ่านระบบแปลภาษา ห้ามวาดข้อความไทยลงในภาพ ยกเว้นโลโก้เกม
