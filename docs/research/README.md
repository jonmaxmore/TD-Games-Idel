# งานวิจัย: สรุปรวมและสิ่งที่ต้องตัดสินใจ

> ทุกข้อในรายงานติดป้ายว่าเป็นข้อมูล การตีความ หรือยังไม่รู้
> ตัวเลขตลาดมาจากผลค้นหา (เปิดหน้าเว็บต้นทางไม่ได้) ตัวเลขที่ใช้ตัดสินใจลงทุนต้องตรวจซ้ำกับต้นฉบับก่อน

## 1. สองรายงานบอกเรื่องเดียวกัน
**ตัวเกมยังไม่สนุกพอจะพิสูจน์ตลาด และเรากำลังลงทุนภาพ เอนจิน และ esports ก่อนพิสูจน์ความสนุก**

| เรื่อง | ฝั่ง design (วัดจาก sim) | ฝั่งตลาด (แหล่งอ้างอิง) |
|---|---|---|
| ความยาวด่าน / จังหวะ | ด่าน 20 waves ใช้ 23–29 นาที ผู้เล่นรอ 80% ของเวลา สั่งการ ~1 ครั้ง/นาที | เกมมือถือแนว strategy เล่นครั้งละสั้น TD ที่รอดใช้รอบ 3–5 นาที |
| ความหลากหลาย | waves เหมือนเดิมทุกรอบ สำนักโลหะคุ้มกว่าสำนักอื่น 1.5–4 เท่า คัมภีร์ยุทธ์ไม่เปลี่ยนผล | roguelite / build ที่หลากหลายเป็นตัวขับ retention หลักของ TD ปี 2025–26 |
| PvP 1v1 เรือธง | ยังไม่มีตัวเลขกติกา มีช่องโหว่เชิงโครงสร้าง | ไม่มีเกมไหนพิสูจน์รูปแบบนี้ ต้องมีผู้เล่นออนไลน์จำนวนมาก esports TD ที่ประสบความสำเร็จมีแค่ Clash Royale (ขนาด Supercell) |
| เว็บก่อน + Unity | ใช้ Unity ทำให้ต้องแก้กฎสองภาษา ช่วงที่ต้องปรับเกมบ่อยที่สุด | Poki ต้องการไฟล์ < 8 MB, Unity WebGL ราว 11 MB, มือถือไทย 57% ราคา < $200 → **ข้อมูลไม่สนับสนุนเว็บก่อนเมื่อใช้ Unity** |
| ธีมจอมยุทธ / แนวตั้ง | — | แนวตั้ง: ข้อมูลสนับสนุน · ธีมจีน: ผู้ชมไทยชอบคอนเทนต์จีน แต่ไม่มีหลักฐานว่าขาย TD ได้ ต้องทดสอบด้วยโฆษณาก่อน |
| รายได้ | — | gacha แบบไม่ขายพลังทำเงินต่อผู้เล่นได้น้อยกว่าเกมที่ขายตัวละครแรงมาก, rewarded ads 10–15% สูงเกินสำหรับไทย, บัตรเดือน 99 ฿ ต่ำกว่าราคาตลาด |

## 2. แผนที่เสนอ (ต้องให้เจ้าของเกมอนุมัติ)
1. **หยุดลงทุนภาพจริงชั่วคราว** และใช้ 2–3 สัปดาห์ทำให้บท 1 สนุกด้วยภาพ placeholder ตามข้อ NOW ใน design-review §6
   - เรียก wave ถัดไปได้ระหว่างสู้ พร้อมโบนัส
   - waves สุ่มจาก seed ตามสูตรใน data และมีบอสที่ wave 10/20
   - ปรับสมดุลสำนัก และให้พิษ/เผาเคารพห้าธาตุ
   - ชีวิต 10 และศัตรูแต่ละชนิดหักชีวิตไม่เท่ากัน
   - ผสานศิษย์และใช้ไม้ตายมีต้นทุน
   - แก้ 4 blocker เช่น มือสังหารเงาออกก่อนสำนักที่มองเห็นได้
   - ทุกข้อมีตัววัดอัตโนมัติ B1–B12 ใน sim
2. **เปลี่ยนลำดับแพลตฟอร์มเป็น Android ไทยก่อน** เว็บใช้เป็นเดโม ลิงก์ชวนเล่น co-op และร้านค้าตรง (ช่องทางจ่ายนอก store คิดเป็น 38% ของรายได้เกมมือถือ SEA)
3. **v1.0 นำด้วย** เนื้อเรื่อง + raid แบบ async + co-op ส่วน ranked เปิดเป็นช่วงเวลา
   - ก่อนเลือกโหมดเรือธง ให้กำหนดตัวเลขบุก–ตั้งรับ 1v1 แล้วทดสอบด้วย bot เทียบกับโหมดสมมาตร
   - เก็บรากฐาน esports ไว้ (sim, replay, ranked แฟร์) แต่ยังไม่ลงทุนจัดแข่งจนกว่าผ่านเกณฑ์ผู้เล่น
4. **ทดสอบธีมก่อนจ้างภาพเต็ม:** ยิงโฆษณาทดสอบ (creative test) ธีมจอมยุทธในไทย วัด CTR/CPI เทียบธีมอื่น
5. **ปรับตัวเลขรายได้:** ลดสัดส่วนโฆษณา, บัตรเดือนราว $4.99, ทบทวนว่าโมเดล "ไม่ขายพลังทุกโหมด PvP" ทำรายได้ได้พอไหม (ประมาณ $1–5 ต่อดาวน์โหลด)
6. **KPI soft launch:** D1 40% / D7 15% เป็นเกณฑ์ "ไปต่อ" และ D1 < 30% / D7 < 8% เป็นเกณฑ์ "คิดใหม่" (ค่ากลางตลาด D1 ~22%, D7 < 4%)

## 3. ข้อมูลในเอกสารเดิมที่ต้องแก้
- Age of Origins ไม่ใช่ "gacha TD" แต่เป็น MMO strategy ที่มี TD เป็นมินิเกม
- เพิ่ม Kingdom Rush Battles (PvP TD 1v1 เปิดทั่วโลก ต.ค. 2025) ใน competitors.md
- Summoners War: Rush ไม่ใช่คู่แข่งตรงที่สุดแล้ว
- กฎ map pool "ห่างไม่เกิน 1%" ต้องใช้ ~38,000 เกม หรือเล่นคู่ seed สลับฝั่ง
- วีรชน "±2%" วัดไม่ได้ เพราะ bot ชนะ 100% ต้องมีด่านวัดที่ bot ชนะราว 50%
- ความขัดแย้ง 21 จุดระหว่างเอกสาร ข้อมูล และโค้ด (design-review §5)
