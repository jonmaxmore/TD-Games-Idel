# Spec: แกนเกม — ตรรกะที่ทุกระบบต้องตามนี้

> **สถานะ: อนุมัติแล้ว (2026-10-23)** · ตัวเลขอยู่ใน `docs/data/pve.json` ตรวจด้วย `npm run economy:check`
> **ที่มา:** เจ้าของเกมเล่นแล้วบอกว่า
> - ไม่รู้ว่าวางตัวไหนตรงไหน
> - เลือกสำนักแล้วไม่มีความหมาย
> - ศัตรูและ wave ไม่มีเหตุผล
> - ไม่รู้ว่าเล่นไปเพื่ออะไร
> - ระบบไอเท็มยังไม่ตกผลึก
>
> **เอกสารนี้มาก่อนเอกสารอื่น:** ถ้า [pve-economy](../design/pve-economy.md), [roster](../design/roster.md), [liveops](../design/liveops.md), [economy](../design/economy.md) หรือ [GDD](../GDD.md) ขัดกับเอกสารนี้ ให้ถือตามเอกสารนี้ (§7) ตัวเลขจริงจะย้ายไปอยู่ใน `docs/data` ในขั้นที่ 2

## หลักคิด (ใช้ตัดสินทุกข้อ)
1. **ทุกการตัดสินใจต้องมีข้อมูลพอ:** ถ้าผู้เล่นต้องเดา แปลว่าเราออกแบบไม่ครบ
2. **ทุกอย่างที่ได้ต้องมีที่ใช้ และทุกอย่างที่ใช้ต้องมีที่มา:** ไม่มีไอเท็มลอยๆ
3. **ศัตรูทุกชนิดมีคำตอบอย่างน้อยหนึ่งบทบาท และบทบาททุกแบบมีศัตรูที่ต้องใช้มัน:** ผู้เล่นจึงต้องผสมทีมในทุกสำนัก
4. **ของน้อยแต่ชัดดีกว่าของเยอะแต่งง:** เปิดตัวด้วยระบบที่จำเป็น ระบบอื่นค่อยเปิดตาม season

## 1. เล่นไปเพื่ออะไร (บันไดเป้าหมาย)

| ช่วงเวลา | ผู้เล่นทำอะไร | ได้อะไร | เอาไปทำอะไรต่อ |
|---|---|---|---|

| **ราย season (9 สัปดาห์)** | ranked ศึกเงา, ตั๋วยุทธภพ | ลีก ตราประจำ season ชุด | โชว์บนโปรไฟล์ ซึ่งเป็นเป้าระยะยาวของผู้เล่นสาย PvP |

**สิ่งที่ต้องเห็นบนจอเสมอ:** "เป้าถัดไป" 1 บรรทัดในลานสำนัก เลือกอันที่ใกล้ที่สุด เช่น
- "ผ่าน 1-6 เพื่อปลดศิลาหลอม"
- "อีก 2 ดาวได้หีบบทที่ 1"
- "วีรชนประจำสัปดาห์เหลือ 3 วัน"

## 2. ข้อมูลก่อนตัดสินใจในด่าน

### 2.1 แผงวางศิษย์ (ใช้ระบบวาง 2 ขั้นที่มีแล้ว: เลือก → ดูตัวอย่าง → ยืนยัน)
เมื่อเลือกศิษย์ แผงแสดงข้อมูลนี้ ทุกค่าอ่านจาก data:
- **บทบาท:** ไอคอนและชื่อ เช่น "ตรึง"
- **ดาเมจต่อวินาที** และ **ระยะ** ระยะเห็นเป็นวงบนแผนที่
- **ตีอากาศได้หรือไม่:** แสดงไอคอนนกขีดฆ่าถ้าตีไม่ได้
- **"เก่งกับ:"** ไอคอนศัตรูที่บทบาทนี้รับมือได้ (ตาราง §3.2)
- **ถนนที่ศิษย์ตัวนี้จะคุม:** ช่องถนนในวงระยะสว่างขึ้น ช่องถนนที่ยังไม่มีศิษย์คนไหนตีถึงเป็นสีจาง ผู้เล่นจึงเห็นช่องโหว่ของผัง

### 2.2 แถบ wave ถัดไป (มีข้อมูลอยู่แล้วใน sim: `nextRecipe`)
- ชื่อสูตร wave + ไอคอนศัตรูที่จะมา + จำนวน
- คุณสมบัติเด่น 1 บรรทัด เช่น "ฝูงบินข้ามหลังคา"
- **"ต้องการ:"** บทบาทที่รับมือได้ เช่น "ตีอากาศ ×2 ขึ้นไป"
- ขึ้นสีแดงถ้าผังตอนนี้ยังไม่มีตัวตอบ ใช้ตาราง §3.2 กับศิษย์ที่วางอยู่

### 2.3 ระหว่างสู้
- ตัวเลขดาเมจและไอคอนสถานะบนศัตรู (มีแล้ว)
- ศัตรูหลุดเข้าประตู: ขึ้นชื่อชนิดศัตรูและเหตุผล เช่น "นักฆ่าล่องหน หลุดเพราะไม่มีตัวเปิดเผย" ผู้เล่นจะได้รู้ว่าแพ้เพราะอะไร

## 3. ตรรกะศัตรูและ wave

### 3.1 แต่ละบทสอนทีละเรื่อง (บทที่ 1)

| ด่าน | ศัตรูใหม่ | บทเรียน | บทบาทที่ใช้ตอบ |
|---|---|---|---|
| T-0 | ทหารลัทธิ (`cultist`) | วาง อัป เรียก wave เร็ว | ทุกบทบาท |
| 1-2 | นักวิ่ง (`runner`) พุ่ง 2 ช่อง | ศัตรูเร็วต้องชะลอ | **ตรึง** |
| 1-4 | ยักษ์เกราะ (`brute`) ลดดาเมจ 5 ต่อครั้ง | ตัวหนาต้องตีแรงต่อครั้ง | **กระบี่หน้า** |
| 1-6 | หุ่นศพ (`puppet`) แตกเป็น 3 | ฝูงต้องตีวงกว้าง | **ปราณวง** |
| 1-8 | นักกระโดด (`leaper`) บินข้ามหลังคา | ต้องมีตัวตีอากาศ | กระบี่หน้า / ปราณวง (บทบาทที่ตีอากาศได้) |
| 1-9 | หมอผี (`healer`) ฟื้นเลือดเพื่อน | ต้องฆ่าก่อน หรือกดฟื้นด้วยพิษ/ไฟ | **สะสม** |
| 1-10 | **บอสบท:** ราชาโจร + นักฆ่าล่องหน (`assassin`) | สอบทุกเรื่อง + ต้องมีตัวเปิดเผย | **ค้ำ** (เปิดเผยที่ขั้น 2) |
| 1-12 | บอสใหญ่ + ทุกชนิดคละ | ผังต้องครบ 5 บทบาท | ทั้งหมด |

### 3.2 ตารางศัตรู ↔ บทบาท (ใช้ทั้งแผงวาง §2.1 และแถบ wave §2.2)

| ศัตรู | คุณสมบัติ | บทบาทที่ตอบ | ทำไม |
|---|---|---|---|
| `runner` | เร็ว พุ่ง | ตรึง | ชะลอแล้วตัวอื่นตีทัน |
| `brute` | เกราะลบดาเมจต่อครั้ง | กระบี่หน้า | ตีครั้งละแรง เกราะกินสัดส่วนน้อย |
| `puppet` | แตกเป็น 3 | ปราณวง | ตีวงกว้างโดนทั้งฝูง |
| `leaper` | บิน | บทบาทที่ตีอากาศได้ (ข้อมูล `hitsAir`) | วัชระศิลาและบางบทบาทตีไม่ถึง |
| `healer` | ฟื้นเลือดเพื่อน | สะสม | สถานะพิษ/ไฟกดการฟื้น (กฎใหม่ในขั้นที่ 3) |
| `assassin` | ล่องหน | ค้ำ (เปิดเผย) / ตรึง (มึนแล้วมองเห็น) | กฎเดิมใน sim |
| `mimic` | ทนธาตุที่โดนล่าสุด | ศิษย์สหายต่างธาตุ | บังคับให้ผสม |

### 3.3 สูตร wave ต้องอ่านออก
- **สูตรเดิม** (`enemies.json > waveRecipes`): ผสม, บุกเร็ว, เกราะหนัก, ทางหลังคา, หุ่นศพ, ฝูงสมุน
- **แต่ละสูตรผูกกับบทบาทที่ต้องใช้** ข้อมูลนี้แสดงในแถบ §2.2:
  - บุกเร็ว → ตรึง
  - เกราะหนัก → กระบี่หน้า
  - ทางหลังคา → ตีอากาศ
  - หุ่นศพ / ฝูงสมุน → ปราณวง
- **เพิ่มฟิลด์ `needsRoles` ใน `waveRecipes`** (ขั้นที่ 2)
- สูตรไม่ซ้ำกันติดกัน (มีแล้ว) และ**ห้ามสุ่มสูตรที่ต้องใช้บทบาทที่ผู้เล่นยังไม่ได้ปลด**

## 4. สำนักมีความหมาย

เลือกสำนักแล้วสิ่งต่อไปนี้ต้องเปลี่ยนทั้งหมด (ขั้นที่ 3 ทำไฟกับพิษก่อน):

| สิ่งที่เปลี่ยน | สำนักหงส์เพลิง | หุบไผ่หยก |
|---|---|---|
| **ศิษย์ 5 บทบาท** (ชื่อจาก roster §5) | ขนหงส์เจาะ · พัดเพลิง · กำแพงเพลิง · ถ่านเพลิง · เตาหลอม | ลูกดอกเป่า · ใบไผ่ปลิว · เถาวัลย์ · ขลุ่ยพิษ · หมอยาหุบไผ่ |
| **กฎสำนัก** | ไฟเผาต่อเนื่อง ยิ่งโดนนานยิ่งแรง | พิษลามไปตัวข้างเคียงเมื่อเป้าตาย |
| **วิธีชนะ (ผังที่ดี)** | ให้ศัตรูอยู่ในไฟนานที่สุด: วางตรงทางยาวและวงวน | วางเป็นกลุ่มตรงที่ศัตรูเดินเป็นแพ ให้พิษลาม |
| **จุดอ่อน** | ศัตรูเร็ว (ไฟยังไม่ทันแรง) | ตัวเกราะหนา, ตัวเร็วที่ผ่านก่อนพิษทำงาน |
| **ภาพ** | ส้มแดง ขนนกไฟ พัด ประกาย | เขียว ใบไผ่ เถา ฟองพิษ |
| **UI** | กรอบปุ่ม แถบบน และตราในลานสำนักเป็นสีสำนัก | เหมือนกัน แต่สีเขียว |

**สถานะ (2026-10-23):**
- ทำแล้วใน sim ทั้ง TS และ C# พร้อม golden `fire-1-12` / `wood-1-12` และ Unity
- **เกณฑ์ S1/S2 อยู่ใน `balance.test.ts`:** bot ชนะ 1-12 ทั้ง 4 seed ทั้งสองสำนัก
- **ข้อสังเกต:** สำนัก roster ชนะ 1-12 ได้โดยไม่เสียชีวิตเลย ง่ายกว่าแบบเดิมที่ชนะ 6/8 ความยากของบทที่ 1 สำหรับสำนัก roster ต้องปรับหลังเจ้าของเกมเล่น (**NOT ASSESSED**: bot ยังวางแบบหมุนบทบาท วัด "ผังที่ชนะต่างกัน" ไม่ได้)

**ผลที่ต้องวัดได้ (เกณฑ์ขั้นที่ 3):**
- bot ของทั้งสองสำนักชนะ 1-12 ได้ใกล้กัน (ต่างกันไม่เกิน ±3%)
- **ผังที่ชนะต่างกัน**: วัดตำแหน่งที่ bot วางแล้วต้องไม่ซ้ำกัน

2. ดาวเต็มแล้ว ตัวซ้ำแยกเป็นตราวีรชน (#11) แล้วไปใช้ที่ร้านตราวีรชน
3. ไม่มีวัสดุขึ้นขั้นแยก (แก้ข้อขัดใน liveops ที่มีแต่ที่ใช้ ไม่มีที่มา)

**ส่วนเกินไปไหน:** ปราณ คัมภีร์ และศิลาทะลวงขั้นที่เต็มเพดาน แปลงเป็นแต้มกิลด์ในอัตราคงที่ ไม่มีของที่เก็บแล้วไร้ค่า

**เลื่อนไป Season 1+** (ยังไม่มีในเกม เพื่อไม่ให้ผู้เล่นงง):
- ของวิเศษ: `relic_ticket`, `relic_essence`
- ชุด: `outfit_ticket`, `skin_shard`
- `forge_core`, `reroll_stone`, `hero_shard_any`
- บำเพ็ญ/prestige: `merit`

**ตัดทิ้ง:** สีย้อม, ชิ้นส่วนธงกิลด์ (มีแต่ที่มา ไม่มีที่ใช้)

## 6. ผังลานสำนัก (lobby)

**แถบล่าง 5 ปุ่ม** ปลดตามด่าน ปุ่มที่ยังล็อกบอกว่าปลดที่ไหน

| ปุ่ม | ข้างในมีอะไร | ปลดเมื่อ |
|---|---|---|
| **ศึก** (ปุ่มกลาง ใหญ่สุด) | แผนที่เนื้อเรื่อง → ด่านถัดไป · ศึกเงา (บุก/ตั้งผัง) · ranked · ดันเจี้ยนรายวัน · บอสรายวัน | เปิดตั้งแต่แรก · ศึกเงาปลดเมื่อจบบท 1 · ดันเจี้ยนปลดที่ 1-6 |
| **ศิษย์** | รายชื่อศิษย์และวีรชน → **หน้าข้อมูลตัวละคร**: ภาพการ์ด, บทบาท, ค่าพลัง, ท่า/สกิลแต่ละขั้น, ศัตรูที่เก่งด้วย · แท็บ: อัปเลเวล / ดาว / อุปกรณ์ + ตีบวก / วิชา | ข้อมูลกับอัปเลเวลเปิดที่ 1-2 · อุปกรณ์และตีบวกเปิดที่ 1-6 · วิชาเปิดที่ 1-8 |
| **ลานสำนัก** (หน้าแรก) | หีบ idle · "เป้าถัดไป" · ภารกิจรายวัน/รายสัปดาห์ · จดหมาย · อีเวนต์ | เปิดตั้งแต่แรก |
| **ศาลา** (gacha) | ตู้วีรชนประจำสัปดาห์ · ตู้ถาวร · ตู้อุปกรณ์ · แสดงอัตรา pity spark และประวัติการสุ่ม | 1-4 |
| **ร้าน** | หยก · แพ็ก · บัตรรายเดือน · ตั๋วยุทธภพ · ร้านตราวีรชน · ร้านกิลด์ · ร้าน PvP | 1-4 |

**กิลด์:** เข้าได้จากปุ่มบนแถบบน ปลดเมื่อจบบท 1 ระบบเต็มเปิดตามปฏิทินใน liveops §2.1
